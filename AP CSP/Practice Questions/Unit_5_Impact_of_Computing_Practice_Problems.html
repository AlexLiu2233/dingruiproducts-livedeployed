  • (C) Ben encrypts with Amara's public key; only Amara's private key can decrypt it, and a certificate authority's digital certificate helps validate that a public key really belongs to the claimed ownerBen 用 Amara 的公钥加密；只有 Amara 的私钥能解密，而证书颁发机构（certificate authority）签发的数字证书有助于验证某把公钥确实属于其声称的所有者
  • (D) Anyone who intercepts the ciphertext can decrypt it using Amara's public key, since the public key is public任何截获密文的人都可以用 Amara 的公钥解密，因为公钥是公开的
Q15HARDAP MC5.6 Safe Computing[1]

A small company wants to reduce the risk of unauthorized access to its laptops and servers. The IT lead proposes four measures. Measure 1: install and update virus and malware scanning software Measure 2: apply operating system and application updates promptly Measure 3: require strong passwords and multifactor authentication Measure 4: connect to any available open Wi-Fi network to save mobile data costs一家小公司希望降低其笔记本电脑和服务器被未经授权访问的风险。IT 负责人提出了四项措施。 措施 1：安装并更新病毒和恶意软件扫描程序 措施 2：及时安装操作系统和应用程序更新 措施 3：要求使用强密码和多因素身份验证 措施 4：为节省移动数据费用，连接任何可用的开放 Wi-Fi 网络

Which of these measures would help protect the company's computing resources, and which would not?这些措施中，哪些有助于保护公司的计算资源，哪一项无助于保护？

  • (A) Measures 1, 2, and 3 help; measure 4 increases risk because data sent over public networks can be intercepted, for example through a rogue access point措施 1、2、3 有帮助；措施 4 会增加风险，因为在公共网络上传输的数据可能被截获，例如通过恶意接入点（rogue access point）
  • (B) Only measure 3 helps; scanning software and updates are unrelated to unauthorized access只有措施 3 有帮助；扫描软件和系统更新与未经授权的访问无关
  • (C) All four measures help, because open Wi-Fi is encrypted by default四项措施都有帮助，因为开放 Wi-Fi 默认是加密的
  • (D) Measures 1 and 4 help; updates usually introduce new bugs, so measure 2 should be avoided措施 1 和 4 有帮助；更新通常会引入新缺陷，所以应避免措施 2
