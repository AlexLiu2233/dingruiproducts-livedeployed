Skill 1.1技能 1.1

Real Numbers, the Number Line and Absolute Value实数、数轴与绝对值

Learning objectives学习目标
  • Classify a number as natural, whole, integer, rational or irrational, and place it on a number line.
  • Decide whether a decimal is rational by checking whether it terminates or repeats, and write a repeating decimal as a fraction.
  • Compare and order real numbers given as fractions, decimals and square roots.
  • Interpret absolute value as distance from a point and solve $|x-a|=b$.
  • Apply the order of operations and the sign rules to evaluate an expression.
  • 把一个数分类为自然数 (natural)、非负整数 (whole)、整数 (integer)、有理数 (rational) 或无理数 (irrational)，并在数轴 (number line) 上标出。
  • 通过小数是否有限或循环来判断它是否为有理数，并把循环小数写成分数。
  • 比较并排序以分数、小数和平方根给出的实数。
  • 把绝对值 (absolute value) 理解为到某点的距离，并解 $|x-a|=b$。
  • 运用运算顺序和符号规则计算表达式。

The real numbers fill the whole number line. Every real number is either rational (it can be written as a fraction $\frac{p}{q}$ of integers with $q\neq 0$) or irrational (it cannot). In decimal form a rational number either terminates, such as $-\frac{9}{4}=-2.25$, or repeats forever, such as $\frac{3}{11}=0.\overline{27}$. An irrational number has a decimal expansion that never ends and never repeats, such as $\sqrt{2}$ and $\pi$.

实数布满整条数轴。每个实数要么是有理数 (rational，可以写成整数之比 $\frac{p}{q}$，$q\neq 0$)，要么是无理数 (irrational)。用小数表示时，有理数要么有限，例如 $-\frac{9}{4}=-2.25$，要么无限循环，例如 $\frac{3}{11}=0.\overline{27}$。无理数的小数展开不终止也不循环，例如 $\sqrt{2}$ 和 $\pi$。

Two traps: a square root of a perfect square is rational ($\sqrt{49}=7$), and a fraction such as $\frac{22}{7}$ is rational even though it only approximates the irrational number $\pi$. A square root of a positive integer that is not a perfect square is irrational.

两个陷阱：完全平方数的平方根是有理数 ($\sqrt{49}=7$)；像 $\frac{22}{7}$ 这样的分数是有理数，虽然它只是无理数 $\pi$ 的近似值。不是完全平方数的正整数的平方根是无理数。

Worked Example 1.1: classify numbers例题 1.1：给数分类

Classify each number as rational or irrational: $\sqrt{49}$, $\sqrt{20}$, $0.\overline{27}$, $-\frac{9}{4}$, $\pi$.

  1. $\sqrt{49}$: $49=7^2$, so $\sqrt{49}=7$, an integer. Rational.
  2. $\sqrt{20}$: $20$ is not a perfect square ($4^2=16$ and $5^2=25$), so $\sqrt{20}=2\sqrt{5}$ never terminates or repeats. Irrational.
  3. $0.\overline{27}$: repeating, so rational: $0.\overline{27}=\frac{27}{99}=\frac{3}{11}$.
  4. $-\frac{9}{4}$: a fraction of integers, equal to $-2.25$. Rational.
  5. $\pi$: irrational.

Why it works: rational means a ratio of integers; terminating and repeating decimals always are, and non-repeating infinite decimals never are.

把下列各数分类为有理数或无理数：$\sqrt{49}$，$\sqrt{20}$，$0.\overline{27}$，$-\frac{9}{4}$，$\pi$。

  1. $\sqrt{49}$：$49=7^2$，所以 $\sqrt{49}=7$，是整数。有理数。
  2. $\sqrt{20}$：$20$ 不是完全平方数（$4^2=16$，$5^2=25$），所以 $\sqrt{20}=2\sqrt{5}$ 不终止也不循环。无理数。
  3. $0.\overline{27}$：循环小数，所以是有理数：$0.\overline{27}=\frac{27}{99}=\frac{3}{11}$。
  4. $-\frac{9}{4}$：整数之比，等于 $-2.25$。有理数。
  5. $\pi$：无理数。

原理：有理数就是整数之比；有限小数和循环小数一定是，不循环的无限小数一定不是。

Worked Example 1.2: order real numbers例题 1.2：给实数排序

Write $-\frac{7}{3}$, $\sqrt{5}$, $-2.3$, $2.2$, $\frac{9}{4}$ from least to greatest.

  1. Convert to decimals: $-\frac{7}{3}\approx -2.333$, $\sqrt{5}\approx 2.236$, $-2.3$, $2.2$, $\frac{9}{4}=2.25$.
  2. Negatives first: $-2.333$ is farther left than $-2.3$, so $-\frac{7}{3}<-2.3$.
  3. Positives: $2.2<2.236<2.25$, so $2.2<\sqrt{5}<\frac{9}{4}$.
  4. Answer: $-\frac{7}{3},\ -2.3,\ 2.2,\ \sqrt{5},\ \frac{9}{4}$.

Why it works: on the number line, left means smaller; a common format (decimals) makes the comparison mechanical.

把 $-\frac{7}{3}$，$\sqrt{5}$，$-2.3$，$2.2$，$\frac{9}{4}$ 从小到大排列。

  1. 化为小数：$-\frac{7}{3}\approx -2.333$，$\sqrt{5}\approx 2.236$，$-2.3$，$2.2$，$\frac{9}{4}=2.25$。
  2. 先排负数：$-2.333$ 在 $-2.3$ 的左边，所以 $-\frac{7}{3}<-2.3$。
  3. 再排正数：$2.2<2.236<2.25$，所以 $2.2<\sqrt{5}<\frac{9}{4}$。
  4. 答案：$-\frac{7}{3},\ -2.3,\ 2.2,\ \sqrt{5},\ \frac{9}{4}$。

原理：数轴上越靠左越小；统一成同一种形式（小数）后比较就是机械操作。

Absolute value as distance绝对值就是距离

The absolute value $|a|$ is the distance from $a$ to $0$ on the number line, so it is never negative: $|5|=5$ and $|-5|=5$. More generally $|x-a|$ is the distance between $x$ and $a$. The equation $|x-a|=b$ with $b>0$ therefore has two solutions, $x=a+b$ and $x=a-b$. If $b<0$ there is no solution, because a distance cannot be negative.

绝对值 (absolute value) $|a|$ 是 $a$ 到 $0$ 的距离，所以不会是负数：$|5|=5$，$|-5|=5$。更一般地，$|x-a|$ 是 $x$ 与 $a$ 之间的距离。因此方程 $|x-a|=b$ 在 $b>0$ 时有两个解 $x=a+b$ 和 $x=a-b$。若 $b<0$ 则无解，因为距离不能为负。

Worked Example 1.3: solve an absolute value equation例题 1.3：解绝对值方程

Solve $|2x-3|=9$.

  1. Split into two cases: $2x-3=9$ or $2x-3=-9$.
  2. First case: $2x=12$, so $x=6$.
  3. Second case: $2x=-6$, so $x=-3$.
  4. Check: $|2\cdot 6-3|=|9|=9$ and $|2\cdot(-3)-3|=|-9|=9$. Both work, so $x=6$ or $x=-3$.

Why it works: an absolute value equals $9$ exactly when the expression inside equals $9$ or $-9$.

解 $|2x-3|=9$。

  1. 分成两种情况：$2x-3=9$ 或 $2x-3=-9$。
  2. 第一种：$2x=12$，所以 $x=6$。
  3. 第二种：$2x=-6$，所以 $x=-3$。
  4. 检验：$|2\cdot 6-3|=|9|=9$，$|2\cdot(-3)-3|=|-9|=9$。两个都成立，所以 $x=6$ 或 $x=-3$。

原理：绝对值等于 $9$，当且仅当里面的式子等于 $9$ 或 $-9$。

Worked Example 1.4: order of operations with signs例题 1.4：带符号的运算顺序

Evaluate $-3^2+4(5-8)^2\div 6$.

  1. Parentheses first: $5-8=-3$.
  2. Exponents: $-3^2=-(3^2)=-9$ and $(-3)^2=9$.
  3. Multiply and divide left to right: $4\cdot 9=36$, then $36\div 6=6$.
  4. Add: $-9+6=-3$.

Why it works: the exponent binds only to the number directly before it, so $-3^2$ is the opposite of $3^2$, not $(-3)^2$.

计算 $-3^2+4(5-8)^2\div 6$。

  1. 先算括号：$5-8=-3$。
  2. 再算指数：$-3^2=-(3^2)=-9$，$(-3)^2=9$。
  3. 乘除从左到右：$4\cdot 9=36$，再 $36\div 6=6$。
  4. 最后相加：$-9+6=-3$。

原理：指数只作用于它前面紧挨着的数，所以 $-3^2$ 是 $3^2$ 的相反数，而不是 $(-3)^2$。

Common mistakes
  • Writing $\sqrt{a+b}=\sqrt{a}+\sqrt{b}$. For example $\sqrt{9+16}=5$, not $3+4=7$.
  • Reading $-3^2$ as $9$. The exponent applies to $3$ only, so the value is $-9$.
  • Giving one solution to $|x-a|=b$. Both $a+b$ and $a-b$ are solutions when $b>0$.
  • Calling a non-terminating decimal irrational without checking that it does not repeat: $0.\overline{27}$ is rational.
常见错误
  • 误认为 $\sqrt{a+b}=\sqrt{a}+\sqrt{b}$ 成立。例如 $\sqrt{9+16}=5$，不是 $3+4=7$。
  • 把 $-3^2$ 读成 $9$。指数只作用于 $3$，所以值是 $-9$。
  • $|x-a|=b$ 只给一个解。$a+b$ 和 $a-b$ 在 $b>0$ 时都是解。
  • 没有检查是否循环就把无限小数说成无理数：$0.\overline{27}$ 是有理数。

Exponents, Radicals and Scientific Notation指数、根式与科学记数法

Learning objectives学习目标
  • Apply the exponent laws, including zero, negative and rational exponents, to simplify an expression.
  • Convert between radical form $\sqrt[n]{a}$ and exponent form $a^{1/n}$.
  • Simplify a radical by pulling out perfect-square factors, and add or subtract like radicals.
  • Rationalize a denominator that contains a square root.
  • Multiply and divide numbers in scientific notation and write the answer in correct form.
  • 运用指数 (exponent) 运算法则，包括零指数、负指数和有理指数，化简 (simplify) 表达式。
  • 在根式形式 $\sqrt[n]{a}$ 与指数形式 $a^{1/n}$ 之间互相转换。
  • 通过提出完全平方因子来化简根式 (radical)，并对同类根式做加减。
  • 对分母含平方根的分式做分母有理化。
  • 用科学记数法 (scientific notation) 做乘除运算，并把结果写成规范形式。

Worked Example 2.1: simplify with exponent laws例题 2.1：用指数法则化简

Simplify $\dfrac{(2x^3y^{-2})^3}{4x^5y^{-1}}$ and write the answer with positive exponents.

  1. Power of a product: $(2x^3y^{-2})^3=2^3x^{9}y^{-6}=8x^9y^{-6}$.
  2. Divide coefficients: $\frac{8}{4}=2$.
  3. Subtract exponents of each base: $x^{9-5}=x^4$ and $y^{-6-(-1)}=y^{-5}$.
  4. Positive exponents: $2x^4y^{-5}=\dfrac{2x^4}{y^5}$.

Why it works: each law just counts factors; a negative exponent moves a factor to the other side of the fraction bar.

化简 $\dfrac{(2x^3y^{-2})^3}{4x^5y^{-1}}$，答案用正指数表示。

  1. 积的乘方：$(2x^3y^{-2})^3=2^3x^{9}y^{-6}=8x^9y^{-6}$。
  2. 系数相除：$\frac{8}{4}=2$。
  3. 同底数的指数相减：$x^{9-5}=x^4$，$y^{-6-(-1)}=y^{-5}$。
  4. 改成正指数：$2x^4y^{-5}=\dfrac{2x^4}{y^5}$。

原理：每条法则都只是在数因子的个数；负指数把因子移到分数线的另一侧。

Rational exponents and radicals有理指数与根式

The exponent $\frac{1}{n}$ means the $n$th root: $a^{1/n}=\sqrt[n]{a}$. A general rational exponent splits into a root and a power: $a^{m/n}=\left(\sqrt[n]{a}\right)^m$. Take the root first, because it keeps the numbers small.

指数 $\frac{1}{n}$ 表示 $n$ 次方根：$a^{1/n}=\sqrt[n]{a}$。一般的有理指数拆成根与幂：$a^{m/n}=\left(\sqrt[n]{a}\right)^m$。先开根，数字会更小。

Worked Example 2.2: evaluate rational exponents例题 2.2：计算有理指数

Evaluate $27^{2/3}$, $16^{-3/4}$ and $\left(\frac{9}{4}\right)^{3/2}$.

  1. $27^{2/3}$: the cube root of $27$ is $3$, and $3^2=9$.
  2. $16^{-3/4}$: a negative exponent flips it: $\frac{1}{16^{3/4}}$. The fourth root of $16$ is $2$, and $2^3=8$, so the value is $\frac{1}{8}$.
  3. $\left(\frac{9}{4}\right)^{3/2}$: the square root of $\frac{9}{4}$ is $\frac{3}{2}$, and $\left(\frac{3}{2}\right)^3=\frac{27}{8}$.

Why it works: the denominator of the exponent is the root index and the numerator is the power.

To simplify a radical, factor out the largest perfect square: $\sqrt{72}=\sqrt{36\cdot 2}=6\sqrt{2}$. To remove a root from a denominator, multiply top and bottom by the root, or by the conjugate when the denominator is a sum.

Worked Example 2.3: combine radicals and rationalize例题 2.3：合并根式并有理化

(a) Simplify $\sqrt{72}+\sqrt{50}-\sqrt{8}$. (b) Rationalize $\dfrac{10}{3+\sqrt{5}}$.

Scientific notation科学记数法

A number in scientific notation is written $m\times 10^k$ with $1\leq m<10$ and $k$ an integer. To multiply, multiply the $m$ parts and add the exponents $k$. To divide, divide the $m$ parts and subtract the exponents. If the $m$ part leaves the interval from $1$ to $10$, shift the decimal point and adjust $k$.

科学记数法把数写成 $m\times 10^k$，其中 $1\leq m<10$，$k$ 为整数。相乘时，$m$ 部分相乘，指数 $k$ 相加；相除时，$m$ 部分相除，指数相减。若 $m$ 部分跑出 $1$ 到 $10$ 的范围，就移动小数点并调整 $k$。

Worked Example 2.4: multiply and divide in scientific notation例题 2.4：科学记数法的乘除

Compute $(4\times 10^{6})(5\times 10^{-2})$ and $\dfrac{6.4\times 10^{7}}{1.6\times 10^{3}}$.

  1. Multiply the parts: $4\cdot 5=20$ and $10^{6}\cdot 10^{-2}=10^{4}$, so the product is $20\times 10^{4}$.
  2. Normalize: $20\times 10^{4}=2\times 10^{5}$, which is $200{,}000$.
  3. Divide the parts: $\frac{6.4}{1.6}=4$ and $\frac{10^{7}}{10^{3}}=10^{4}$.
  4. Result: $4\times 10^{4}$, which is $40{,}000$.

Why it works: the $m$ parts and the powers of ten are separate factors, so they can be handled separately.

Linear Equations and Literal Equations一次方程与字母方程

Learning objectives学习目标
  • Solve a linear equation in one variable by distributing, combining like terms and using inverse operations to isolate the variable.
  • Clear fractions and decimals by multiplying both sides by a common multiple.
  • Recognize an equation with no solution or with infinitely many solutions.
  • Solve for one variable in a literal equation (a formula) in terms of the others.
  • Check a solution by substituting it into the original equation.
  • 通过去括号、合并同类项和逆运算来分离 (isolate) 变量，求解一元一次方程 (linear equation)。
  • 两边同乘公倍数，去掉分数和小数。
  • 识别无解或有无穷多解的方程。
  • 在字母方程（公式）中用其他字母表示某个变量，即求解 (solve for) 该变量。
  • 把解代回原方程进行检验。

A linear equation in one variable can be written as $ax+b=c$ with $a\neq 0$: the variable appears only to the first power. To solve it, you isolate the variable. Every step does the same thing to both sides, so the two sides stay equal: undo addition with subtraction, undo multiplication with division. The usual order is (1) distribute, (2) clear fractions, (3) collect variable terms on one side and constants on the other, (4) divide by the coefficient.

一元一次方程 (linear equation) 可以写成 $ax+b=c$，其中 $a\neq 0$：变量只以一次方出现。求解就是把变量分离 (isolate) 出来。每一步都对两边做同样的运算，两边就始终相等：用减法抵消加法，用除法抵消乘法。常用顺序是：(1) 去括号，(2) 去分母，(3) 含变量的项移到一边、常数移到另一边，(4) 两边除以系数。

Worked Example 3.1: variables on both sides例题 3.1：两边都有变量

Solve $3(2x-5)=4x+7$.

  1. Distribute: $6x-15=4x+7$.
  2. Collect $x$ terms on the left: subtract $4x$ from both sides: $2x-15=7$.
  3. Collect constants on the right: add $15$: $2x=22$.
  4. Divide by the coefficient: $x=11$.
  5. Check: left side $3(22-5)=3\cdot 17=51$; right side $4\cdot 11+7=51$. Both sides match.

Why it works: each step is an inverse operation applied to both sides, so the solution set never changes.

解 $3(2x-5)=4x+7$。

  1. 去括号：$6x-15=4x+7$。
  2. 把 $x$ 项移到左边：两边减 $4x$：$2x-15=7$。
  3. 把常数移到右边：两边加 $15$：$2x=22$。
  4. 除以系数：$x=11$。
  5. 检验：左边 $3(22-5)=3\cdot 17=51$；右边 $4\cdot 11+7=51$。两边相等。

原理：每一步都是对两边同时做逆运算，所以解集不会改变。

Worked Example 3.2: clear the fractions first例题 3.2：先去分母

Solve $\dfrac{x}{3}+\dfrac{x-1}{4}=5$.

  1. Least common multiple of the denominators: $\operatorname{lcm}(3,4)=12$.
  2. Multiply every term by $12$: $4x+3(x-1)=60$.
  3. Distribute and combine: $4x+3x-3=60$, so $7x-3=60$.
  4. Isolate $x$: $7x=63$, so $x=9$.
  5. Check: $\frac{9}{3}+\frac{8}{4}=3+2=5$.

Why it works: multiplying both sides by the same nonzero number keeps them equal and turns every fraction into an integer coefficient.

解 $\dfrac{x}{3}+\dfrac{x-1}{4}=5$。

  1. 分母的最小公倍数：$\operatorname{lcm}(3,4)=12$。
  2. 每一项都乘 $12$：$4x+3(x-1)=60$。
  3. 去括号并合并：$4x+3x-3=60$，即 $7x-3=60$。
  4. 分离 $x$：$7x=63$，所以 $x=9$。
  5. 检验：$\frac{9}{3}+\frac{8}{4}=3+2=5$。

原理：两边同乘一个非零数仍然相等，并且把每个分数都变成整数系数。

No solution or infinitely many solutions无解或无穷多解

Sometimes the variable cancels completely. If what is left is false, such as $6=5$, the equation has no solution. If what is left is always true, such as $6=6$, the equation is an identity and every real number is a solution. For example $2(x+3)=2x+5$ becomes $6=5$ (no solution), while $2(x+3)=2x+6$ becomes $6=6$ (infinitely many solutions). In the form $ax+b=cx+d$: one solution when $a\neq c$; none when $a=c$ and $b\neq d$; infinitely many when $a=c$ and $b=d$.

有时变量会被完全消去。如果剩下的式子是错的，例如 $6=5$，方程无解 (no solution)。如果剩下的式子总是对的，例如 $6=6$，方程是恒等式，任何实数都是解 (infinitely many solutions)。例如 $2(x+3)=2x+5$ 化为 $6=5$（无解），而 $2(x+3)=2x+6$ 化为 $6=6$（无穷多解）。对 $ax+b=cx+d$：$a\neq c$ 时恰有一个解；$a=c$ 且 $b\neq d$ 时无解；$a=c$ 且 $b=d$ 时有无穷多解。

Literal equations: solve for a variable字母方程：用其他字母表示某个变量

A literal equation is a formula with several letters. To solve for one letter, treat every other letter as a fixed number and use the same inverse operations. Undo the outermost operation first. Write the answer with the target letter alone on one side.

字母方程 (literal equation) 是含有多个字母的公式。要求解 (solve for) 某个字母，就把其他字母都看作固定的数，使用同样的逆运算。先撤销最外层的运算。最后让目标字母单独位于等号一边。

Worked Example 3.3: solve a formula for one variable例题 3.3：从公式中求出一个变量

The area of a trapezoid is $A=\frac{1}{2}h(b_1+b_2)$. Solve for $b_1$.

  1. Undo the $\frac{1}{2}$: multiply both sides by $2$: $2A=h(b_1+b_2)$.
  2. Undo the multiplication by $h$: divide by $h$ (with $h\neq 0$): $\dfrac{2A}{h}=b_1+b_2$.
  3. Undo the addition of $b_2$: $b_1=\dfrac{2A}{h}-b_2$.
  4. Check with numbers: $h=4$, $b_1=3$, $b_2=5$ gives $A=\frac{1}{2}\cdot 4\cdot 8=16$; then $\frac{2\cdot 16}{4}-5=8-5=3$.

Why it works: the letters are numbers you do not know yet, so the same inverse operations apply in reverse order of how the formula builds $A$.

  1. 撤销 $\frac{1}{2}$：两边乘 $2$：$2A=h(b_1+b_2)$。
  2. 撤销乘 $h$：两边除以 $h$（$h\neq 0$）：$\dfrac{2A}{h}=b_1+b_2$。
  3. 撤销加 $b_2$：$b_1=\dfrac{2A}{h}-b_2$。
  4. 用数字检验：取 $h=4$，$b_1=3$，$b_2=5$，得 $A=\frac{1}{2}\cdot 4\cdot 8=16$；而 $\frac{2\cdot 16}{4}-5=8-5=3$。

原理：字母只是暂时未知的数，所以按公式构成 $A$ 的相反顺序做逆运算即可。

Linear, Compound and Absolute Value Inequalities一次不等式、复合不等式与绝对值不等式

An inequality compares two expressions with $<$, $\leq$, $>$ or $\geq$. You solve it with the same inverse operations as an equation, with one extra rule: when you multiply or divide both sides by a negative number, you must reverse the inequality sign. The reason is that multiplying by a negative number reflects the number line: $2<5$, but $-2>-5$. Adding or subtracting any number, or multiplying by a positive number, keeps the direction.

不等式 (inequality) 用 $<$，$\leq$，$>$ 或 $\geq$ 比较两个式子。求解方法和方程一样用逆运算，但多一条规则：两边同乘或同除以负数时，必须改变不等号方向 (reverse the inequality)。原因是乘以负数相当于把数轴翻转：$2<5$，但 $-2>-5$。加减任何数或乘以正数，方向不变。

Worked Example 4.1: divide by a negative例题 4.1：除以负数

Solve $5-3x\geq 17$.

  1. Subtract $5$: $-3x\geq 12$.
  2. Divide by $-3$ and reverse the inequality: $x\leq -4$.
  3. Check a point inside: $x=-5$ gives $5+15=20\geq 17$. True.
  4. Check a point outside: $x=0$ gives $5\geq 17$. False, as expected.

Why it works: dividing by a negative number swaps the order of every pair of numbers, so the sign must flip to stay true.

解 $5-3x\geq 17$。

  1. 两边减 $5$：$-3x\geq 12$。
  2. 两边除以 $-3$，不等号反向：$x\leq -4$。
  3. 检验解集内的点：$x=-5$ 时 $5+15=20\geq 17$，成立。
  4. 检验解集外的点：$x=0$ 时 $5\geq 17$，不成立，符合预期。

原理：除以负数会颠倒每一对数的大小顺序，所以不等号必须反向才能仍然成立。

Compound inequalities复合不等式

A compound inequality joins two conditions. With "and", a solution must satisfy both, so the solution set is the overlap, often written as one chain such as $-2<x\leq 3$. With "or", a solution needs only one, so the set is the union, such as $x<-1$ or $x\geq 4$. For a chain, do each operation to all three parts at once. On a number line, an open circle marks an endpoint that is not included ($<$ or $>$) and a closed dot marks one that is ($\leq$ or $\geq$).

复合不等式 (compound inequality) 把两个条件连在一起。用“且” (and) 连接时，解必须同时满足两个条件，解集是重叠部分，常写成一条连不等式，如 $-2<x\leq 3$。用“或” (or) 连接时，只需满足其一，解集是并集，如 $x<-1$ 或 $x\geq 4$。解连不等式时，每一步对三个部分同时运算。在数轴上，空心圆表示不包含端点（$<$ 或 $>$），实心点表示包含端点（$\leq$ 或 $\geq$）。

Solve $-3<2x+1\leq 7$ and graph the solution.

  1. Subtract $1$ from all three parts: $-4<2x\leq 6$.
  2. Divide all three parts by $2$ (positive, so no reversal): $-2<x\leq 3$.
  3. Graph: open circle at $-2$, closed dot at $3$, shade between (Figure 1.2).
  4. Check the endpoints: $x=3$ gives $2\cdot 3+1=7\leq 7$, included; $x=-2$ gives $-3<-3$, false, so $-2$ is excluded.

Why it works: the chain is two inequalities at once, and the same operation keeps both true.

解 $-3<2x+1\leq 7$ 并画出解集。

  1. 三个部分都减 $1$：$-4<2x\leq 6$。
  2. 三个部分都除以 $2$（正数，不反向）：$-2<x\leq 3$。
  3. 画图：在 $-2$ 画空心圆，在 $3$ 画实心点，中间涂色（图 1.2）。
  4. 检验端点：$x=3$ 时 $2\cdot 3+1=7\leq 7$，包含；$x=-2$ 时 $-3<-3$ 不成立，所以不含 $-2$。

原理：连不等式其实是同时成立的两个不等式，同样的运算使两者都保持成立。

Absolute value inequalities绝对值不等式

Use the distance meaning from Skill 1.1. For $b>0$, $|x-a|<b$ says "within $b$ of $a$", which is the "and" chain $a-b<x<a+b$. And $|x-a|>b$ says "farther than $b$ from $a$", which is the "or" pair $x<a-b$ or $x>a+b$. A quick memory aid: less than gives a segment, greater than gives two rays.

用技能 1.1 中距离的含义。当 $b>0$ 时，$|x-a|<b$ 表示“与 $a$ 的距离小于 $b$”，即“且”型连不等式 $a-b<x<a+b$；$|x-a|>b$ 表示“与 $a$ 的距离大于 $b$”，即“或”型 $x<a-b$ 或 $x>a+b$。记忆方法：小于得到一条线段，大于得到两条射线。

Worked Example 4.3: absolute value inequalities例题 4.3：绝对值不等式

Solve (a) $|x-1|<4$ and (b) $|2x+3|\geq 5$.

  1. (a) Distance from $1$ less than $4$: $-4<x-1<4$, so $-3<x<5$.
  2. (b) Split into an "or" pair: $2x+3\geq 5$ or $2x+3\leq -5$.
  3. (b) Solve each piece: $2x\geq 2$ gives $x\geq 1$; $2x\leq -8$ gives $x\leq -4$.
  4. (b) Answer: $x\leq -4$ or $x\geq 1$. Check $x=1$: $|5|=5\geq 5$, true; $x=0$: $|3|=3$, not $\geq 5$, so $0$ is correctly excluded.

Why it works: an absolute value is a distance, so "less than" keeps $x$ close to the center and "at least" pushes $x$ away on both sides.

解 (a) $|x-1|<4$ 和 (b) $|2x+3|\geq 5$。

  1. (a) 与 $1$ 的距离小于 $4$：$-4<x-1<4$，所以 $-3<x<5$。
  2. (b) 拆成“或”型：$2x+3\geq 5$ 或 $2x+3\leq -5$。
  3. (b) 分别求解：$2x\geq 2$ 得 $x\geq 1$；$2x\leq -8$ 得 $x\leq -4$。
  4. (b) 答案：$x\leq -4$ 或 $x\geq 1$。检验 $x=1$：$|5|=5\geq 5$，成立；$x=0$：$|3|=3$，不满足 $\geq 5$，所以正确地排除了 $0$。

原理：绝对值就是距离，“小于”让 $x$ 靠近中心，“至少”把 $x$ 推向两侧。

Common mistakes
  • Forgetting to reverse the inequality after dividing by a negative coefficient, as in $-3x\geq 12$.
  • Reversing the sign when subtracting a negative number. Only multiplying or dividing by a negative flips it.
  • Writing $|x-a|>b$ as one chain $a-b>x>a+b$, which no number satisfies. It needs "or".
  • Mixing up open and closed endpoints when reading a graph back into symbols.
常见错误
  • 像 $-3x\geq 12$ 那样除以负系数后忘记把不等号反向。
  • 减去一个负数时也把不等号反向。只有乘或除以负数才反向。
  • 把 $|x-a|>b$ 写成一条连不等式 $a-b>x>a+b$，没有任何数满足它。必须用“或”。
  • 把图形读回符号时弄混空心端点和实心端点。

Systems of Linear Equations一次方程组

Learning objectives学习目标

  • Solve a system by elimination, scaling one or both equations so a variable cancels.
  • Interpret the solution as the intersection point of two lines on a graph.
  • Decide whether a system has one solution, no solution or infinitely many by comparing slopes and intercepts.
  • Write and solve a system from a word problem, and answer in context.
  • 用代入法 (substitution) 解二元一次方程组 (system of equations)。
  • 用消元法 (elimination) 解方程组：把一个或两个方程乘以适当的数，使某个变量消去。
  • 把方程组的解解释为图上两条直线的交点。
  • 比较斜率和截距，判断方程组有一个解、无解还是无穷多解。

A system of linear equations is a set of equations that must all be true at once. For two variables, a solution is an ordered pair $(x,y)$ that satisfies both equations, which is a point on both lines. Two algebraic methods do the work. Substitution: solve one equation for a variable and substitute that expression into the other. Elimination: add or subtract multiples of the equations so that one variable cancels. Pick substitution when a variable already has coefficient $1$ or $-1$; pick elimination when the coefficients line up or can be made to line up.

一次方程组 (system of equations) 是必须同时成立的一组方程。对两个变量而言，解是同时满足两个方程的有序数对 $(x,y)$，也就是两条直线的公共点。有两种代数方法。代入法 (substitution)：从一个方程解出某个变量，把这个式子代入另一个方程。消元法 (elimination)：把两个方程的倍数相加或相减，使一个变量消去。当某个变量的系数已经是 $1$ 或 $-1$ 时用代入法；当系数对齐或容易对齐时用消元法。

Worked Example 5.1: substitution例题 5.1：代入法

Solve the system $y=2x-1$ and $x+y=5$.

  1. Substitute $y=2x-1$ into the second equation: $x+(2x-1)=5$.
  2. Solve for $x$: $3x-1=5$, so $3x=6$ and $x=2$.
  3. Back-substitute: $y=2\cdot 2-1=3$.
  4. Check both equations: $3=2\cdot 2-1$ and $2+3=5$. The solution is $(2,3)$, the crossing point in Figure 1.3.

Why it works: in the solution, $y$ and $2x-1$ are the same number, so replacing one with the other leaves a one-variable equation.

解方程组 $y=2x-1$，$x+y=5$。

  1. 代入：把 $y=2x-1$ 代入第二个方程：$x+(2x-1)=5$。
  2. 求 $x$：$3x-1=5$，所以 $3x=6$，$x=2$。
  3. 回代：$y=2\cdot 2-1=3$。
  4. 检验两个方程：$3=2\cdot 2-1$，$2+3=5$。解为 $(2,3)$，即图 1.3 中的交点。

原理：在解处，$y$ 和 $2x-1$ 是同一个数，所以用一个替换另一个后就得到一元方程。

Worked Example 5.2: elimination with scaling例题 5.2：先乘倍数再消元

Solve $3x+2y=16$ and $5x-4y=1$.

  1. Line up the $y$ coefficients: multiply the first equation by $2$: $6x+4y=32$.
  2. Add the equations so $y$ cancels: $(6x+4y)+(5x-4y)=32+1$, so $11x=33$ and $x=3$.
  3. Back-substitute into $3x+2y=16$: $9+2y=16$, so $2y=7$ and $y=3.5$.
  4. Check the other equation: $5\cdot 3-4\cdot 3.5=15-14=1$. The solution is $(3,\,3.5)$.

Why it works: adding two true equations gives a true equation, and choosing the multiplier makes one variable disappear.

解 $3x+2y=16$，$5x-4y=1$。

  1. 使 $y$ 的系数对齐：第一个方程乘 $2$：$6x+4y=32$。
  2. 两式相加消去 $y$：$(6x+4y)+(5x-4y)=32+1$，所以 $11x=33$，$x=3$。
  3. 回代到 $3x+2y=16$：$9+2y=16$，所以 $2y=7$，$y=3.5$。
  4. 检验另一个方程：$5\cdot 3-4\cdot 3.5=15-14=1$。解为 $(3,\,3.5)$。

原理：两个成立的等式相加仍成立，选好倍数就能让一个变量消失。

How many solutions?有几个解？

Write each equation in slope-intercept form $y=mx+b$. Different slopes: the lines cross once, so there is one solution. Same slope, different intercepts: the lines are parallel, so there is no solution. Same slope and same intercept: the equations describe the same line, so there are infinitely many solutions. In standard form $ax+by=c$ and $dx+ey=f$, the system has no solution exactly when $\frac{a}{d}=\frac{b}{e}\neq\frac{c}{f}$ (with nonzero denominators). If you try to solve such a system algebraically, both variables cancel and you are left with a false statement like $0=7$.

把每个方程写成斜截式 $y=mx+b$。斜率不同：两直线相交于一点，有一个解。斜率相同、截距不同：两直线平行，无解。斜率和截距都相同：两个方程表示同一条直线，有无穷多解。对一般式 $ax+by=c$ 和 $dx+ey=f$，当 $\frac{a}{d}=\frac{b}{e}\neq\frac{c}{f}$（分母不为零）时方程组无解。若用代数方法求解这样的方程组，两个变量会同时消去，剩下像 $0=7$ 这样错误的式子。

Worked Example 5.3: write a system from a context例题 5.3：由情境列方程组

A school play sold $150$ tickets. Adult tickets cost 12 dollars and student tickets cost 7 dollars. Ticket revenue was 1,450 dollars. How many adult tickets were sold?

  1. Define variables: $a$ adult tickets, $s$ student tickets.
  2. Write the system: count $a+s=150$; money $12a+7s=1450$.
  3. Substitute $s=150-a$: $12a+7(150-a)=1450$, so $12a+1050-7a=1450$.
  4. Solve: $5a=400$, so $a=80$ and $s=70$.
  5. Check and answer in context: $12\cdot 80+7\cdot 70=960+490=1450$. The play sold $80$ adult tickets.

Why it works: each sentence of the story gives one equation, and two unknowns need two independent equations.

学校话剧共售出 $150$ 张票。成人票每张 12 美元，学生票每张 7 美元。票房收入为 1,450 美元。卖出了多少张成人票？

  1. 设变量：成人票 $a$ 张，学生票 $s$ 张。
  2. 列方程组：张数 $a+s=150$；金额 $12a+7s=1450$。
  3. 代入 $s=150-a$：$12a+7(150-a)=1450$，即 $12a+1050-7a=1450$。
  4. 求解：$5a=400$，所以 $a=80$，$s=70$。
  5. 检验并结合情境作答：$12\cdot 80+7\cdot 70=960+490=1450$。卖出了 $80$ 张成人票。

原理：题目中的每一句信息给出一个方程，两个未知数需要两个独立的方程。

  • Concluding "no solution" when the variables cancel to a true statement like $0=0$. That means infinitely many solutions.

A polynomial is a sum of terms of the form $ax^n$ with whole-number exponents $n$, for example $3x^2-5x+2$. Its degree is the highest exponent. To add or subtract polynomials, combine like terms (same variable, same exponent). To multiply, distribute every term of one factor over every term of the other; for two binomials this is the familiar four products: $(x+a)(x+b)=x^2+(a+b)x+ab$. Three patterns are worth knowing on sight: $(a+b)^2=a^2+2ab+b^2$, $(a-b)^2=a^2-2ab+b^2$ and $(a+b)(a-b)=a^2-b^2$.

多项式 (polynomial) 是形如 $ax^n$（$n$ 为非负整数）的项之和，例如 $3x^2-5x+2$。最高的指数叫次数 (degree)。多项式加减就是合并同类项（变量相同、指数相同）。相乘时，把一个因式的每一项分别乘另一个因式的每一项；两个二项式相乘就是熟悉的四个乘积：$(x+a)(x+b)=x^2+(a+b)x+ab$。有三个公式要一眼认出：$(a+b)^2=a^2+2ab+b^2$，$(a-b)^2=a^2-2ab+b^2$，$(a+b)(a-b)=a^2-b^2$。

Factoring因式分解

To factor is to run multiplication backwards: write a polynomial as a product. Work in this order. (1) Pull out the greatest common factor. (2) For $x^2+bx+c$, find two numbers with product $c$ and sum $b$. (3) For $ax^2+bx+c$ with $a\neq 1$, find two numbers with product $ac$ and sum $b$, split the middle term, and factor by grouping. (4) Look for the special patterns: $a^2-b^2=(a-b)(a+b)$ and $a^2\pm 2ab+b^2=(a\pm b)^2$. Always check by multiplying the factors back out.

因式分解 (factor) 就是把乘法倒过来：把多项式写成乘积。按以下顺序进行。(1) 提取最大公因式。(2) 对 $x^2+bx+c$，找两个数，积为 $c$、和为 $b$。(3) 对 $a\neq 1$ 的 $ax^2+bx+c$，找两个数，积为 $ac$、和为 $b$，拆开中间项再分组分解。(4) 寻找特殊形式：$a^2-b^2=(a-b)(a+b)$ 和 $a^2\pm 2ab+b^2=(a\pm b)^2$。最后一定要把因式乘回去检验。

Worked Example 6.1: factor completely例题 6.1：彻底分解因式

Factor (a) $2x^3-8x^2-24x$ and (b) $6x^2+7x-3$ completely.

  1. (a) Greatest common factor: $2x^3-8x^2-24x=2x(x^2-4x-12)$.
  2. (a) Trinomial: two numbers with product $-12$ and sum $-4$ are $-6$ and $2$, so $2x(x-6)(x+2)$.
  3. (b) Product $ac$: $6\cdot(-3)=-18$. Two numbers with product $-18$ and sum $7$ are $9$ and $-2$.
  4. (b) Split and group: $6x^2+9x-2x-3=3x(2x+3)-1(2x+3)=(3x-1)(2x+3)$.
  5. Check (b): $(3x-1)(2x+3)=6x^2+9x-2x-3=6x^2+7x-3$.

Why it works: splitting the middle term with numbers whose product is $ac$ makes the two halves share a common binomial factor.

彻底分解 (a) $2x^3-8x^2-24x$ 和 (b) $6x^2+7x-3$。

  1. (a) 最大公因式：$2x^3-8x^2-24x=2x(x^2-4x-12)$。
  2. (a) 三项式：积为 $-12$、和为 $-4$ 的两个数是 $-6$ 和 $2$，所以得 $2x(x-6)(x+2)$。
  3. (b) 乘积 $ac$：$6\cdot(-3)=-18$。积为 $-18$、和为 $7$ 的两个数是 $9$ 和 $-2$。
  4. (b) 拆项并分组：$6x^2+9x-2x-3=3x(2x+3)-1(2x+3)=(3x-1)(2x+3)$。
  5. 检验 (b)：$(3x-1)(2x+3)=6x^2+9x-2x-3=6x^2+7x-3$。

原理：用积为 $ac$ 的两个数拆开中间项，前后两半就会有公共的二项式因式。

Solving quadratics: zero product and the quadratic formula解二次方程：零乘积性质与求根公式

The zero product property says: if $AB=0$, then $A=0$ or $B=0$. So to solve a quadratic by factoring, first move every term to one side so the other side is $0$, factor, and set each factor equal to $0$. When the quadratic does not factor nicely, use the quadratic formula: the solutions of $ax^2+bx+c=0$ with $a\neq 0$ are

零乘积性质 (zero product property) 是说：若 $AB=0$，则 $A=0$ 或 $B=0$。所以用因式分解解二次方程时，先把所有项移到一边，使另一边为 $0$，再分解，令每个因式等于 $0$。如果二次式不容易分解，就用求根公式 (quadratic formula)：$a\neq 0$ 时 $ax^2+bx+c=0$ 的解为

$$x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}.$$

$$x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}.$$

The expression under the root, the discriminant $b^2-4ac$, tells you how many real solutions there are before you finish: positive gives two, zero gives one (a repeated root), and negative gives none.

根号下的式子 $b^2-4ac$ 叫判别式 (discriminant)，不必算完就能知道实数解的个数：为正时有两个，为零时有一个（重根），为负时没有实数解。

Worked Example 6.2: solve by factoring例题 6.2：用因式分解求解

Solve $x^2-x=12$.

  1. Set one side to zero: $x^2-x-12=0$.
  2. Factor: product $-12$, sum $-1$ gives $-4$ and $3$: $(x-4)(x+3)=0$.
  3. Zero product property: $x-4=0$ or $x+3=0$, so $x=4$ or $x=-3$.
  4. Check: $16-4=12$ and $9-(-3)=12$.

Why it works: a product is zero only when a factor is zero, which is why the equation must equal $0$ first; $(x-4)(x+3)=12$ would tell you nothing directly.

解 $x^2-x=12$。

  1. 使一边为零：$x^2-x-12=0$。
  2. 分解：积为 $-12$、和为 $-1$ 的两个数是 $-4$ 和 $3$：$(x-4)(x+3)=0$。
  3. 零乘积性质：$x-4=0$ 或 $x+3=0$，所以 $x=4$ 或 $x=-3$。
  4. 检验：$16-4=12$，$9-(-3)=12$。

原理：乘积为零当且仅当某个因式为零，所以必须先让方程等于 $0$；$(x-4)(x+3)=12$ 不能直接得出结论。

Worked Example 6.3: use the quadratic formula例题 6.3：使用求根公式

Solve $2x^2-4x-3=0$. Give exact answers and decimals to three places.

  1. Identify: $a=2$, $b=-4$, $c=-3$.
  2. Discriminant: $b^2-4ac=16-4\cdot 2\cdot(-3)=16+24=40>0$, so there are two real solutions.
  3. Formula: $x=\dfrac{4\pm\sqrt{40}}{4}=\dfrac{4\pm 2\sqrt{10}}{4}=\dfrac{2\pm\sqrt{10}}{2}$.
  4. Decimals: $\sqrt{10}\approx 3.1623$, so $x\approx 2.581$ or $x\approx -0.581$.
  5. Check $x\approx 2.581$: $2(2.581)^2-4(2.581)-3\approx 13.323-10.324-3\approx 0$.

Why it works: the formula is what you get by completing the square on $ax^2+bx+c=0$, so it solves every quadratic, factorable or not.

解 $2x^2-4x-3=0$。给出精确解以及保留三位小数的近似值。

  1. 确定系数：$a=2$，$b=-4$，$c=-3$。
  2. 判别式：$b^2-4ac=16-4\cdot 2\cdot(-3)=16+24=40>0$，所以有两个实数解。
  3. 代入公式：$x=\dfrac{4\pm\sqrt{40}}{4}=\dfrac{4\pm 2\sqrt{10}}{4}=\dfrac{2\pm\sqrt{10}}{2}$。
  4. 小数：$\sqrt{10}\approx 3.1623$，所以 $x\approx 2.581$ 或 $x\approx -0.581$。
  5. 检验 $x\approx 2.581$：$2(2.581)^2-4(2.581)-3\approx 13.323-10.324-3\approx 0$。

原理：求根公式就是对 $ax^2+bx+c=0$ 配方得到的结果，所以无论能否分解，它都能解出每个二次方程。

Common mistakes
  • Dividing both sides by $x$ in an equation like $3x^2=12x$. That loses the solution $x=0$; factor $3x(x-4)=0$ instead.
  • Using the zero product property when the right side is not zero, for example setting each factor of $(x-4)(x+3)=12$ equal to $12$.
  • Dropping the sign of $b$: with $b=-4$, the formula starts with $-b=4$, and $b^2=16$, not $-16$.
  • Dividing only the first term of the numerator by $2a$: $\frac{4\pm 2\sqrt{10}}{4}$ is $\frac{2\pm\sqrt{10}}{2}$, not $1\pm 2\sqrt{10}$.
常见错误
  • 在 $3x^2=12x$ 这样的方程中两边除以 $x$。这会丢掉解 $x=0$；应分解为 $3x(x-4)=0$。
  • 右边不为零时也用零乘积性质，例如令 $(x-4)(x+3)=12$ 的每个因式等于 $12$。
  • 丢掉 $b$ 的符号：$b=-4$ 时公式开头 $-b=4$，而 $b^2=16$，不是 $-16$。
  • 只把分子的第一项除以 $2a$：$\frac{4\pm 2\sqrt{10}}{4}$ 是 $\frac{2\pm\sqrt{10}}{2}$，不是 $1\pm 2\sqrt{10}$。

Rational Expressions and Radical Equations分式与根式方程

Learning objectives学习目标
  • Simplify a rational expression by factoring and cancelling common factors, and state the excluded values.
  • Add and subtract rational expressions over a common denominator.
  • Solve a rational equation by multiplying through by the least common denominator.
  • Solve a radical equation by isolating the radical and squaring both sides.
  • Check every candidate in the original equation and reject any extraneous solution.
  • 通过因式分解约去公因式来化简分式 (rational expression)，并写出使分母为零的排除值。
  • 化为公分母 (common denominator) 后对分式做加减。
  • 两边同乘最简公分母来解分式方程。
  • 先分离根式再两边平方，求解根式方程 (radical equation)。
  • 把每个候选解代回原方程检验，舍去增根 (extraneous solution)。

A rational expression is a fraction whose numerator and denominator are polynomials, such as $\dfrac{x^2-9}{x^2+x-6}$. It is undefined wherever the denominator is $0$, so those values are excluded from the start. To simplify, factor the numerator and the denominator completely and cancel common factors. You may never cancel common terms: in $\frac{x+3}{x+5}$ nothing cancels.

分式 (rational expression) 是分子、分母都是多项式的分数，例如 $\dfrac{x^2-9}{x^2+x-6}$。分母为 $0$ 时分式无意义，所以这些值一开始就要排除。化简时，把分子、分母彻底分解，再约去公共的因式。绝不能约去公共的项：$\frac{x+3}{x+5}$ 中没有可以约去的东西。

Worked Example 7.1: simplify and combine rational expressions例题 7.1：化简与合并分式

(a) Simplify $\dfrac{x^2-9}{x^2+x-6}$. (b) Write $\dfrac{2}{x}+\dfrac{3}{x+1}$ as one fraction.

  1. (a) Factor top and bottom: $\dfrac{(x-3)(x+3)}{(x+3)(x-2)}$.
  2. (a) Cancel the common factor $x+3$: $\dfrac{x-3}{x-2}$, with $x\neq -3$ and $x\neq 2$ (both make the original denominator $0$).
  3. (b) Common denominator: $x(x+1)$. Rewrite: $\dfrac{2(x+1)}{x(x+1)}+\dfrac{3x}{x(x+1)}$.
  4. (b) Add numerators: $\dfrac{2x+2+3x}{x(x+1)}=\dfrac{5x+2}{x(x+1)}$.
  5. Check (b) at $x=1$: $\frac{2}{1}+\frac{3}{2}=3.5$ and $\frac{5+2}{1\cdot 2}=3.5$.

Why it works: fractions add only when their denominators match, and multiplying a fraction by $\frac{x+1}{x+1}$ is multiplying by $1$.

(a) 化简 $\dfrac{x^2-9}{x^2+x-6}$。(b) 把 $\dfrac{2}{x}+\dfrac{3}{x+1}$ 写成一个分式。

  1. (a) 分解分子分母：$\dfrac{(x-3)(x+3)}{(x+3)(x-2)}$。
  2. (a) 约去公因式 $x+3$：$\dfrac{x-3}{x-2}$，且 $x\neq -3$，$x\neq 2$（两者都使原分母为 $0$）。
  3. (b) 公分母：$x(x+1)$。改写为 $\dfrac{2(x+1)}{x(x+1)}+\dfrac{3x}{x(x+1)}$。
  4. (b) 分子相加：$\dfrac{2x+2+3x}{x(x+1)}=\dfrac{5x+2}{x(x+1)}$。
  5. 在 $x=1$ 处检验 (b)：$\frac{2}{1}+\frac{3}{2}=3.5$，$\frac{5+2}{1\cdot 2}=3.5$。

原理：只有分母相同的分数才能相加，而分式乘 $\frac{x+1}{x+1}$ 就是乘 $1$。

Rational equations分式方程

To solve an equation that contains rational expressions, multiply every term by the least common denominator. That clears all fractions and leaves a linear or quadratic equation. Multiplying by an expression that can equal $0$ can create a candidate that makes an original denominator $0$. Such a value is an extraneous solution: it solves the cleared equation but not the original, so you must reject it.

解含有分式的方程时，每一项都乘最简公分母。这样就去掉了所有分母，剩下一次或二次方程。由于所乘的式子可能等于 $0$，可能产生使原分母为 $0$ 的候选解。这样的值叫增根 (extraneous solution)：它满足去分母后的方程，却不满足原方程，必须舍去。

Worked Example 7.2: solve a rational equation例题 7.2：解分式方程

Solve $\dfrac{3}{x}+\dfrac{1}{2}=\dfrac{5}{2x}$.

  1. Excluded value: $x\neq 0$.
  2. Multiply every term by the common denominator $2x$: $6+x=5$.
  3. Solve: $x=-1$, which is not excluded.
  4. Check in the original: $\frac{3}{-1}+\frac{1}{2}=-2.5$ and $\frac{5}{2(-1)}=-2.5$.

Why it works: for $x\neq 0$, multiplying by $2x$ is a reversible step, so the solution of $6+x=5$ is a solution of the original.

解 $\dfrac{3}{x}+\dfrac{1}{2}=\dfrac{5}{2x}$。

  1. 排除值：$x\neq 0$。
  2. 每一项乘公分母 $2x$：$6+x=5$。
  3. 求解：$x=-1$，不是排除值。
  4. 代回原方程检验：$\frac{3}{-1}+\frac{1}{2}=-2.5$，$\frac{5}{2(-1)}=-2.5$。

原理：当 $x\neq 0$ 时，乘 $2x$ 是可逆的步骤，所以 $6+x=5$ 的解就是原方程的解。

Radical equations根式方程

A radical equation has the variable under a root. Isolate the radical on one side, then raise both sides to the power that removes it (square a square root). Squaring is not reversible: $a=b$ implies $a^2=b^2$, but $a^2=b^2$ also holds when $a=-b$. So squaring can introduce an extraneous solution, and every candidate must be checked in the original equation. A principal square root is never negative, which is the usual reason a candidate fails.

根式方程 (radical equation) 的变量在根号里。先把根式单独放在一边，再把两边乘方以去掉根号（平方根就平方）。平方不是可逆的：$a=b$ 能推出 $a^2=b^2$，但 $a=-b$ 时 $a^2=b^2$ 也成立。所以平方可能引入增根 (extraneous solution)，每个候选解都必须代回原方程检验。算术平方根不会是负数，这通常就是候选解不成立的原因。

Worked Example 7.3: a radical equation with an extraneous root例题 7.3：有增根的根式方程

Solve $\sqrt{x+7}=x-5$.

  1. The radical is already isolated. Square both sides: $x+7=(x-5)^2=x^2-10x+25$.
  2. Set to zero and factor: $x^2-11x+18=0$, so $(x-9)(x-2)=0$ and $x=9$ or $x=2$.
  3. Check $x=9$: $\sqrt{16}=4$ and $9-5=4$. It works.
  4. Check $x=2$: $\sqrt{9}=3$ but $2-5=-3$. It fails, so $x=2$ is extraneous.
  5. Answer: $x=9$ only.

Why it works: $x=2$ solves $\sqrt{x+7}=-(x-5)$, which squares to the same quadratic; checking in the original separates the two.

解 $\sqrt{x+7}=x-5$。

  1. 根式已经单独在一边。两边平方：$x+7=(x-5)^2=x^2-10x+25$。
  2. 移项为零并分解：$x^2-11x+18=0$，即 $(x-9)(x-2)=0$，$x=9$ 或 $x=2$。
  3. 检验 $x=9$：$\sqrt{16}=4$，$9-5=4$。成立。
  4. 检验 $x=2$：$\sqrt{9}=3$，但 $2-5=-3$。不成立，所以 $x=2$ 是增根。
  5. 答案：只有 $x=9$。

原理：$x=2$ 满足的是 $\sqrt{x+7}=-(x-5)$，它平方后得到同一个二次方程；代回原方程检验才能把两者区分开。

Common mistakes
  • Cancelling terms instead of factors: $\frac{x^2+4}{x+2}$ is not $x+2$, and $\frac{x+3}{x+5}$ does not simplify.
  • Adding fractions by adding numerators and denominators: $\frac{2}{x}+\frac{3}{x+1}$ is not $\frac{5}{2x+1}$.
  • Squaring a side term by term: $(x-5)^2$ is $x^2-10x+25$, not $x^2+25$ or $x^2-25$.
  • Skipping the check, and so reporting an extraneous solution as an answer.
常见错误
  • 约去项而不是因式：$\frac{x^2+4}{x+2}$ 不等于 $x+2$，$\frac{x+3}{x+5}$ 不能化简。
  • 把分子相加、分母相加来做分数加法：$\frac{2}{x}+\frac{3}{x+1}$ 不等于 $\frac{5}{2x+1}$。
  • 逐项平方：$(x-5)^2$ 是 $x^2-10x+25$，不是 $x^2+25$ 或 $x^2-25$。
  • 省略检验，把增根当作答案。
Exam tip考试提示

Expect the extraneous root among the answer choices. A choice that lists both candidates, such as "$x=2$ or $x=9$", is the classic trap for students who skip the check. Plug in the answer choices to the original equation, not the squared one. A square root evaluates quickly on your calculator, so this backsolve check takes seconds.

预料到选项中会出现增根。 同时列出两个候选解的选项，比如“$x=2$ or $x=9$”，正是给不检验的学生准备的陷阱。把选项代入 (plug in the answer choices) 原方程，而不是平方后的方程。用计算器 (calculator) 求平方根很快，所以这种代入检验 (backsolving) 只需几秒。
