A discrete random variable (RV) $X$ takes a list of values $x_1, x_2, \ldots$ with probabilities $P(X = x_i)$ summing to $1$. The list of (value, probability) pairs is the probability distribution of $X$. Two non-negotiables: $$ P(X = x_i) \ge 0, \qquad \sum_{i} P(X = x_i) = 1. $$ These two rules are the only things you ever need to check that a table actually is a probability distribution.
离散随机变量（discrete random variable）$X$ 取一组取值 $x_1, x_2, \ldots$，对应概率 $P(X = x_i)$ 之和为 $1$。 所有 (取值, 概率) 对组成的列表就是 $X$ 的概率分布（probability distribution）。两条不可妥协的公理： $$ P(X = x_i) \ge 0, \qquad \sum_{i} P(X = x_i) = 1. $$ 一张表是不是真正的概率分布，只需要核对这两条规则。
Discrete Probability Distribution: Axioms离散概率分布：公理
$$ 0 \le P(X = x_i) \le 1 $$ $$ \sum_{i} P(X = x_i) = 1 $$
What "random variable" really means "随机变量"到底是什么 A random variable is a function from outcomes of an experiment to numbers. Rolling a die, $X$ = the number shown, is a discrete RV taking values $\{1, 2, 3, 4, 5, 6\}$ each with probability $\tfrac{1}{6}$. The distribution doesn't care why each outcome has its probability, only what the values and probabilities are. This abstraction is what lets the same toolkit handle dice, coin flips, server requests, and exam scores. 随机变量（random variable）本质上是一个把实验结果映射到数字的函数。掷骰子时，令 $X$ = 朝上面的点数，这就是一个离散随机变量，取值集合为 $\{1, 2, 3, 4, 5, 6\}$，每个值的概率都是 $\tfrac{1}{6}$。分布本身并不关心每个结果为何具有那种概率，它只关心值和概率是什么。这种抽象正是同一套工具能同时处理骰子、抛硬币、服务器请求和考试成绩的原因。

▸ Going deeper: Cumulative distribution function (CDF)▸ 深入：累积分布函数（CDF）

For a discrete RV $X$, the cumulative distribution function (CDF) is

$$ F(x) = P(X \le x) = \sum_{x_i \le x} P(X = x_i). $$

$F$ is a non-decreasing step function from $0$ to $1$. Two facts to know:

  • $P(a < X \le b) = F(b) - F(a)$: take care with strict vs. weak inequalities for discrete RVs.
  • $P(X \ge k) = 1 - F(k - 1)$: the "$1$ minus CDF" trick is the standard route for tail probabilities, especially with binomial on the GDC.

On a GDC, binomCdf(n, p, k) returns $P(X \le k)$ for $X \sim B(n, p)$. To get $P(X > k)$, compute 1 − binomCdf(n, p, k); to get $P(X \ge k)$, compute 1 − binomCdf(n, p, k − 1).

对离散随机变量 $X$，累积分布函数（cumulative distribution function / CDF）定义为

$$ F(x) = P(X \le x) = \sum_{x_i \le x} P(X = x_i). $$

$F$ 是从 $0$ 上升到 $1$ 的非递减阶梯函数。需要掌握的两件事：

  • $P(a < X \le b) = F(b) - F(a)$：离散随机变量的严格不等号与非严格不等号必须分清。
  • $P(X \ge k) = 1 - F(k - 1)$："$1$ 减 CDF"的技巧是处理尾部概率的标准套路，尤其是用 GDC 算二项分布时。

The expected value of a discrete RV is the probability-weighted mean of its values. $$ E(X) = \mu = \sum_{i} x_i\, P(X = x_i). $$ $E(X)$ is the long-run average: the mean value per trial you would approach if you repeated the experiment a very large number of times. It does not need to be one of the values $X$ can take (e.g. a die's $E(X) = 3.5$).
离散随机变量的期望值（expected value）就是用概率加权得到的取值平均。 $$ E(X) = \mu = \sum_{i} x_i\, P(X = x_i). $$ $E(X)$ 是长期平均：把同一个实验重复非常多次时，每次试验的平均值所趋近的数值。它本身不必是 $X$ 真正能取到的值（比如骰子的 $E(X) = 3.5$）。

Fair game 公平游戏 A game is called fair if $E(\text{net gain}) = 0$. If $E(\text{net gain}) > 0$ the game favours the player; if $E(\text{net gain}) < 0$ it favours the house. Fair-game questions ask either "is the game fair?" or "what stake makes the game fair?"; both reduce to finding $E(\text{net gain})$, setting it equal to $0$ and solving. 当净收益的期望 $E(\text{net gain}) = 0$ 时，称游戏为公平（fair game）。若 $E(\text{net gain}) > 0$，游戏对玩家有利；若 $E(\text{net gain}) < 0$，游戏对庄家（house）有利。公平游戏题要么问"游戏公平吗？"，要么问"赌注定为多少游戏才公平？"；两类问题都归结为求出 $E(\text{net gain})$，令其等于 $0$ 并求解。
Worked Example: Expected value of a die例题：骰子的期望值

Problem: $X$ is the number shown on a fair six-sided die. Find $E(X)$.

Each value $1, 2, \ldots, 6$ has probability $\tfrac{1}{6}$. Apply the definition:

$$ E(X) = \sum_{x=1}^{6} x \cdot \tfrac{1}{6} = \tfrac{1}{6}(1 + 2 + 3 + 4 + 5 + 6) = \tfrac{21}{6} = 3.5. $$

So the long-run average roll is $3.5$, even though $3.5$ is never an actual outcome.

题目：$X$ 表示一颗均匀六面骰子掷出的点数。求 $E(X)$。

每个取值 $1, 2, \ldots, 6$ 的概率都是 $\tfrac{1}{6}$。按定义计算：

$$ E(X) = \sum_{x=1}^{6} x \cdot \tfrac{1}{6} = \tfrac{1}{6}(1 + 2 + 3 + 4 + 5 + 6) = \tfrac{21}{6} = 3.5. $$

长期平均点数是 $3.5$，尽管骰子永远掷不出 $3.5$ 这个数。

Variance measures the average squared deviation from the mean. Two equivalent formulas; the second is usually faster: $$ \text{Var}(X) = E\!\left[(X - \mu)^2\right] = E(X^2) - [E(X)]^2. $$ Compute $E(X^2) = \sum x_i^2\, P(X = x_i)$ from the table, square $E(X)$, subtract. 方差（variance）衡量取值相对于均值的平均平方偏差。两个等价公式，第二个通常更快： $$ \text{Var}(X) = E\!\left[(X - \mu)^2\right] = E(X^2) - [E(X)]^2. $$ 从分布表算出 $E(X^2) = \sum x_i^2\, P(X = x_i)$，把 $E(X)$ 平方，再相减。标准差（standard deviation）$\sigma = \sqrt{\text{Var}(X)}$。
Variance: Two Equivalent Forms方差：两种等价形式
$$ \text{Var}(X) = \sum_{i} (x_i - \mu)^{2}\, P(X = x_i) $$ $$ = E(X^{2}) - \mu^{2} = \sum_{i} x_i^{2}\, P(X = x_i) - \mu^{2} $$

Standard deviation $\sigma = \sqrt{\text{Var}(X)}$. Variance has units of "$X$-squared"; SD has the units of $X$, so SD is what you report.

标准差 $\sigma = \sqrt{\text{Var}(X)}$。方差的单位是"$X$ 的平方"；标准差的单位与 $X$ 相同，所以最终汇报时用的是标准差。

▸ Going deeper: Deriving $\text{Var}(X) = E(X^{2}) - \mu^{2}$▸ 深入：推导 $\text{Var}(X) = E(X^{2}) - \mu^{2}$

Start from the definition and expand the square:

$$ \text{Var}(X) = E\!\left[(X - \mu)^{2}\right] = E\!\left[X^{2} - 2\mu X + \mu^{2}\right]. $$

Linearity of expectation (see 3.8) gives $E(aX + b) = aE(X) + b$. Apply it term by term, remembering that $\mu = E(X)$ is a constant:

$$ = E(X^{2}) - 2\mu\, E(X) + \mu^{2} = E(X^{2}) - 2\mu \cdot \mu + \mu^{2} = E(X^{2}) - \mu^{2}. \;\;\blacksquare $$

This is the form to use for calculation. The other form, $E[(X - \mu)^{2}]$, makes the meaning clearer (average squared deviation) but is usually slower to evaluate by hand.

从定义出发，把平方展开：

$$ \text{Var}(X) = E\!\left[(X - \mu)^{2}\right] = E\!\left[X^{2} - 2\mu X + \mu^{2}\right]. $$

期望的线性性（linearity of expectation，见 3.8 节）给出 $E(aX + b) = aE(X) + b$。逐项使用，注意 $\mu = E(X)$ 是常数：

$$ = E(X^{2}) - 2\mu\, E(X) + \mu^{2} = E(X^{2}) - 2\mu \cdot \mu + \mu^{2} = E(X^{2}) - \mu^{2}. \;\;\blacksquare $$

这是计算时应使用的形式。另一种形式 $E[(X - \mu)^{2}]$ 更直观（平均平方偏差），但手算时通常更慢。

Why squared? 为什么要平方？ Deviations $(X - \mu)$ can be positive or negative, and their expected value is always zero: $E(X - \mu) = E(X) - \mu = 0$. So the average deviation tells you nothing about spread. Squaring makes every deviation non-negative, and averaging then gives a meaningful measure of distance from the mean. The square root (the standard deviation) recovers the original units. Absolute deviations also measure spread, but they do not obey the simple rule $\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)$ for independent variables (see 3.8), which is what makes variance so useful. 偏差 $(X - \mu)$ 可正可负，而且它的期望恒为零：$E(X - \mu) = E(X) - \mu = 0$。所以平均偏差无法反映离散程度。平方后每个偏差都变成非负，再取平均才得到有意义的"到均值的距离"度量。开方（即标准差）又把单位还原。绝对偏差也能衡量离散程度，但它不满足独立变量的简单法则 $\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)$（见 3.8 节），而这正是方差如此有用的原因。

▸ Going deeper: Why $E(X) = np$▸ 深入：为什么 $E(X) = np$

Write $X = X_{1} + X_{2} + \cdots + X_{n}$ where $X_{i} = 1$ if trial $i$ is a success and $X_{i} = 0$ otherwise. Each $X_{i}$ is a Bernoulli RV with $E(X_{i}) = p$ (since $E(X_{i}) = 1 \cdot p + 0 \cdot (1 - p) = p$). The expected value of a sum is the sum of the expected values, so

$$ E(X) = E(X_{1}) + E(X_{2}) + \cdots + E(X_{n}) = np. $$

For variance (HL), each $X_{i}$ has $E(X_{i}^{2}) = p$ (since $X_{i}^{2} = X_{i}$ for a $\{0, 1\}$ variable), so $\text{Var}(X_{i}) = p - p^{2} = p(1 - p)$. The $X_{i}$ are independent, so variances add (Section 3.8):

$$ \text{Var}(X) = n \cdot p(1 - p). $$

This decomposition into Bernoulli pieces is the cleanest derivation. It also generalizes immediately: any sum of $n$ independent Bernoulli$(p)$ trials is binomial, regardless of whether they come from "the same experiment."

▸ Going deeper: Why are so many real distributions approximately normal?▸ 深入：为何现实中那么多分布近似正态？

The Central Limit Theorem says: if $X_{1}, X_{2}, \ldots, X_{n}$ are independent, identically distributed RVs with finite mean and variance, then for large $n$ their sum (and hence their mean) is approximately normal, whatever the distribution of the individual $X_{i}$.

This is why quantities such as heights and measurement errors are often close to bell-shaped: each is the combined effect of many small, roughly independent contributions. You do not need the CLT for the calculations in this unit, but it explains why the normal distribution is such a common model.

A continuous RV $X$ has a probability density function (PDF) $f(x)$ satisfying $f(x) \ge 0$ and $\int_{-\infty}^{\infty} f(x)\, dx = 1$. Crucially, $P(X = a) = 0$ for any single value $a$: only intervals can have positive probability. So $P(a \le X \le b) = P(a < X < b)$ for continuous RVs (unlike discrete).

▸ Going deeper: Why $P(X = a) = 0$ for a continuous RV▸ 深入：为什么连续随机变量满足 $P(X = a) = 0$

For a continuous RV with PDF $f$, the probability of exactly $X = a$ is

$$ P(X = a) = \int_{a}^{a} f(x)\, dx = 0. $$

This is not a quirk: it follows from measuring probability as area instead of point masses. A density assigns probability to intervals, and any single value has interval length $0$. Two consequences:

  • For continuous RVs, $P(a \le X \le b) = P(a < X < b) = P(a < X \le b)$. Inequality endpoints don't matter.
  • For discrete RVs, $P(X = a) > 0$ in general, and strict vs. weak inequalities do matter (Section 3.4's trap).

This is a key reason that the discrete and continuous "languages" are not interchangeable, even though the formulas look alike.

Three rules cover this entire section. $$ E(aX + b) = a\, E(X) + b, \qquad \text{Var}(aX + b) = a^{2}\, \text{Var}(X). $$ For any RVs $X$ and $Y$ (independent or not): $$ E(X \pm Y) = E(X) \pm E(Y). $$ For independent RVs $X$ and $Y$ only: $$ \text{Var}(X \pm Y) = \text{Var}(X) + \text{Var}(Y). $$ A linear combination of independent normals is normal, with mean and variance given by the rules above.
整节内容只需要三条规则。线性变换（linear transformation）： $$ E(aX + b) = a\, E(X) + b, \qquad \text{Var}(aX + b) = a^{2}\, \text{Var}(X). $$ 对任意随机变量 $X$、$Y$（无论是否独立）： $$ E(X \pm Y) = E(X) \pm E(Y). $$ 仅当 $X$、$Y$ 独立时： $$ \text{Var}(X \pm Y) = \text{Var}(X) + \text{Var}(Y). $$ 独立正态分布的线性组合（linear combination）仍服从正态分布，新分布的均值与方差由上述规则给出。
Linear Transformation of a Single RV单个随机变量的线性变换
$$ E(aX + b) = a\, E(X) + b $$ $$ \text{Var}(aX + b) = a^{2}\, \text{Var}(X) $$

$b$ shifts the centre but not the spread; $a$ scales both, and the variance by $a^{2}$. In words: Var(aX + b) is a² times Var(X), whatever the value of b, and the standard deviation is multiplied by |a|.

$b$ 只平移分布的中心，不改变离散程度；$a$ 同时缩放二者，而方差按 $a^{2}$ 缩放。用文字说：无论 b 取何值，Var(aX + b) 都等于 a² 乘以 Var(X)，而标准差乘以 |a|。

Sums and Differences of Independent RVs独立随机变量的和与差
$$ E(aX + bY) = a\, E(X) + b\, E(Y) $$ $$ \text{Var}(aX + bY) = a^{2}\, \text{Var}(X) + b^{2}\, \text{Var}(Y) \quad \text{(if $X \perp Y$)} $$

The expectation rule holds without the independence assumption: linearity of expectation is unconditional. The variance rule requires independence.

期望规则不需要独立性假设：期望的线性性（linearity of expectation）无条件成立。方差规则则必须依赖独立性。

Linear Combination of Independent Normals独立正态分布的线性组合
$$ X_{i} \sim N(\mu_{i}, \sigma_{i}^{2}) \text{ independent} \;\Longrightarrow\; \sum_{i=1}^{n} a_{i} X_{i} \sim N\!\left(\sum_{i=1}^{n} a_{i}\mu_{i},\; \sum_{i=1}^{n} a_{i}^{2}\sigma_{i}^{2}\right) $$

In particular, $X + Y \sim N(\mu_{1} + \mu_{2},\; \sigma_{1}^{2} + \sigma_{2}^{2})$ and $X - Y \sim N(\mu_{1} - \mu_{2},\; \sigma_{1}^{2} + \sigma_{2}^{2})$. Note the plus on the variances even for differences.

特别地，$X + Y \sim N(\mu_{1} + \mu_{2},\; \sigma_{1}^{2} + \sigma_{2}^{2})$，$X - Y \sim N(\mu_{1} - \mu_{2},\; \sigma_{1}^{2} + \sigma_{2}^{2})$。注意求差时方差仍是相加。

▸ Going deeper: Deriving $\text{Var}(aX + b) = a^{2}\,\text{Var}(X)$▸ 深入：推导 $\text{Var}(aX + b) = a^{2}\,\text{Var}(X)$

Let $Y = aX + b$. Apply linearity of expectation to compute the mean:

$$ E(Y) = E(aX + b) = a E(X) + b = a\mu + b. $$

Now apply the definition of variance:

$$ \text{Var}(Y) = E\!\left[(Y - E(Y))^{2}\right] = E\!\left[(aX + b - a\mu - b)^{2}\right] = E\!\left[(a(X - \mu))^{2}\right]. $$

Factor out the $a^{2}$ (which is a constant):

$$ = a^{2}\, E\!\left[(X - \mu)^{2}\right] = a^{2}\, \text{Var}(X). \;\;\blacksquare $$

Two takeaways: the shift $b$ disappears (variance is translation-invariant: spread does not depend on where you measure from), and the scale factor $a$ enters squared (because squaring is what made variance non-negative in the first place). The fact that $|a|$ matters but $\text{sign}(a)$ doesn't is also a useful cross-check: $\text{Var}(-X) = \text{Var}(X)$.

设 $Y = aX + b$。用期望的线性性算出均值：

$$ E(Y) = E(aX + b) = a E(X) + b = a\mu + b. $$

再代入方差的定义：

$$ \text{Var}(Y) = E\!\left[(Y - E(Y))^{2}\right] = E\!\left[(aX + b - a\mu - b)^{2}\right] = E\!\left[(a(X - \mu))^{2}\right]. $$

把常数 $a^{2}$ 提到期望外面：

$$ = a^{2}\, E\!\left[(X - \mu)^{2}\right] = a^{2}\, \text{Var}(X). \;\;\blacksquare $$

两点要记：常数项 $b$ 完全消失（方差具有平移不变性：离散程度与"从哪测量"无关）；缩放因子 $a$ 进入时是平方（因为正是平方运算才让方差非负）。一个有用的交叉验证：只有 $|a|$ 重要、$\text{sign}(a)$ 无关紧要，即 $\text{Var}(-X) = \text{Var}(X)$。

▸ Going deeper: Why $\text{Var}(X \pm Y) = \text{Var}(X) + \text{Var}(Y)$ for independent RVs▸ 深入：为什么独立随机变量满足 $\text{Var}(X \pm Y) = \text{Var}(X) + \text{Var}(Y)$

Expand using the alternate variance formula and the fact that for independent RVs $E(XY) = E(X)E(Y)$ (a consequence of independence):

$$ \text{Var}(X + Y) = E\!\left[(X + Y)^{2}\right] - [E(X + Y)]^{2}. $$

Expand the square inside the first expectation:

$$ = E(X^{2}) + 2 E(XY) + E(Y^{2}) - [E(X) + E(Y)]^{2}. $$

Independence kicks in on $E(XY) = E(X)\, E(Y)$. The squared mean expands as $[E(X)]^{2} + 2 E(X) E(Y) + [E(Y)]^{2}$, so the $2 E(XY)$ and the $-2 E(X) E(Y)$ cancel exactly:

$$ = \!\left[E(X^{2}) - [E(X)]^{2}\right] + \!\left[E(Y^{2}) - [E(Y)]^{2}\right] = \text{Var}(X) + \text{Var}(Y). \;\;\blacksquare $$

For $\text{Var}(X - Y)$, write $X - Y = X + (-Y)$ and use $\text{Var}(-Y) = (-1)^{2}\text{Var}(Y) = \text{Var}(Y)$, so variances still add. Variance always adds for independent RVs, even when the RVs are subtracted.

使用方差的另一种形式，并利用独立随机变量满足 $E(XY) = E(X)E(Y)$（这是独立性的一个推论）：

$$ \text{Var}(X + Y) = E\!\left[(X + Y)^{2}\right] - [E(X + Y)]^{2}. $$

展开第一项里的平方：

$$ = E(X^{2}) + 2 E(XY) + E(Y^{2}) - [E(X) + E(Y)]^{2}. $$

独立性出现在 $E(XY) = E(X)\, E(Y)$。把均值的平方展开成 $[E(X)]^{2} + 2 E(X) E(Y) + [E(Y)]^{2}$，则 $2 E(XY)$ 与 $-2 E(X) E(Y)$ 恰好抵消：

$$ = \!\left[E(X^{2}) - [E(X)]^{2}\right] + \!\left[E(Y^{2}) - [E(Y)]^{2}\right] = \text{Var}(X) + \text{Var}(Y). \;\;\blacksquare $$

对于 $\text{Var}(X - Y)$，写成 $X - Y = X + (-Y)$，再用 $\text{Var}(-Y) = (-1)^{2}\text{Var}(Y) = \text{Var}(Y)$，方差依然相加。独立随机变量的方差永远相加，即使两个变量是相减的。

Why normals are special 正态分布为何特殊 Most distributions don't close under addition: the sum of two independent binomials with different $p$ is not binomial; the sum of two independent uniforms on the same interval is triangular, not uniform. But normals are special: the family is closed under linear combinations of independent variables, and the new parameters come from the mean and variance rules above. This is why many multi-step problems reduce to "compute a single normal probability." 大多数分布在相加运算下并不封闭：两个 $p$ 不同的独立二项分布之和不再是二项分布；同一区间上两个独立均匀分布之和是三角分布而非均匀分布。但正态分布是个特例：独立变量的线性组合仍是正态分布，新分布的参数由上面的均值与方差规则给出。这就是为什么许多多步骤题目都能归结成"算一个正态概率"。

Problem: $X$ has $E(X) = 10$ and $\text{Var}(X) = 4$. Let $Y = 3X - 5$. Find $E(Y)$ and $\text{Var}(Y)$.

So $\sigma_{Y} = 6$ (three times $\sigma_{X} = 2$, since scale $a = 3$ multiplies SD by $|a|$). Why this works: the $-5$ moves every value by the same amount, so it changes the mean but not the spread.
