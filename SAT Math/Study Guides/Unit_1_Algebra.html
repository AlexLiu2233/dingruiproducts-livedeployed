Skill 1.1技能 1.1

Linear Equations in One Variable一元一次方程

Learning objectives学习目标
  • Solve a linear equation in one variable using inverse operations, including equations that need distribution and combining like terms.
  • Decide, from the form $ax=b$, whether an equation has one solution, no solution, or infinitely many solutions.
  • Find the value of a parameter $k$ that makes an equation have no solution or infinitely many solutions.
  • Isolate a variable in a formula that contains several letters.
  • Translate a word problem into a linear equation, solve it, and answer in context.
  • 用逆运算解一元一次方程 (linear equation in one variable)，包括需要去括号、合并同类项的方程。
  • 由 $ax=b$ 的形式判断方程有唯一解、无解 (no solution) 还是有无穷多解 (infinitely many solutions)。
  • 求参数 $k$ 的值，使方程无解或有无穷多解。
  • 在含多个字母的公式中分离 (isolate) 出某个变量。
  • 把应用题 (word problem) 翻译成一次方程，求解并结合情境作答。

A linear equation in one variable is an equation whose unknown appears only to the first power, such as $3x+5=20$. The goal is to isolate the variable: use inverse operations (addition undoes subtraction, multiplication undoes division) on both sides, in the reverse of the order in which the operations were applied to $x$. Whatever you do to one side you must do to the other.

一元一次方程 (linear equation in one variable) 是未知数只出现一次幂的方程，例如 $3x+5=20$。目标是把变量分离出来：对等式两边同时使用逆运算 (inverse operations，加法与减法互逆，乘法与除法互逆)，顺序与 $x$ 被运算的顺序相反。对一边做什么，就对另一边做什么。

Solving step by step逐步求解

  • Distribute and remove parentheses: $3(2x-5)=6x-15$.
  • Combine like terms on each side.
  • Collect the variable terms on one side and the constants on the other.
  • Divide by the coefficient of $x$.
  • Check by substituting back into the original equation.
  • 去括号：$3(2x-5)=6x-15$。
  • 分别合并两边的同类项。
  • 把含变量的项移到一边，常数移到另一边。
  • 除以 $x$ 的系数。
  • 代回原方程检验。
Worked Example 1.1: solve an equation with parentheses例题 1.1：解含括号的方程

Solve $3(2x-5)+4=5x+8$.

  1. Distribute: $6x-15+4=5x+8$.
  2. Combine like terms: $6x-11=5x+8$.
  3. Collect variable terms: subtract $5x$ from both sides to get $x-11=8$.
  4. Isolate: add $11$ to both sides, so $x=19$.
  5. Check: left side $3(2\cdot 19-5)+4=3\cdot 33+4=103$; right side $5\cdot 19+8=103$.

Why it works: each step replaces the equation with an equivalent one that has the same solution.

解 $3(2x-5)+4=5x+8$。

  1. 去括号：$6x-15+4=5x+8$。
  2. 合并同类项：$6x-11=5x+8$。
  3. 移项：两边同时减去 $5x$，得 $x-11=8$。
  4. 分离变量：两边同时加 $11$，得 $x=19$。
  5. 检验：左边 $3(2\cdot 19-5)+4=3\cdot 33+4=103$；右边 $5\cdot 19+8=103$。

原理：每一步都换成同解的等价方程。

One solution, no solution, or infinitely many一个解、无解、无穷多解

After you collect terms, every linear equation in one variable reduces to $ax=b$. There are three outcomes. If $a\neq 0$ there is exactly one solution, $x=\frac{b}{a}$. If $a=0$ and $b\neq 0$ the equation says $0=b$, which is false for every $x$, so there is no solution. If $a=0$ and $b=0$ the equation says $0=0$, which is true for every $x$, so there are infinitely many solutions.

合并同类项后，每个一元一次方程都化为 $ax=b$，共有三种结果。若 $a\neq 0$，恰有一个解 $x=\frac{b}{a}$。若 $a=0$ 且 $b\neq 0$，方程变成 $0=b$，对任何 $x$ 都不成立，所以无解。若 $a=0$ 且 $b=0$，方程变成 $0=0$，对任何 $x$ 都成立，所以有无穷多解。

A shortcut for parameter questions: when the coefficients of $x$ on the two sides are equal after simplifying, compare the constants. Equal constants give infinitely many solutions; different constants give no solution.

参数题的捷径：化简后若两边 $x$ 的系数相等，就比较常数项。常数项相等则有无穷多解；常数项不同则无解。

Worked Example 1.2: find $k$ for infinitely many solutions例题 1.2：求 $k$ 使方程有无穷多解

For what value of $k$ does $6(x-2)=2(3x+k)$ have infinitely many solutions?

  1. Expand: $6x-12=6x+2k$.
  2. Compare: the coefficients of $x$ are both $6$, so the equation is true for every $x$ exactly when the constants match.
  3. Match constants: $-12=2k$, so $k=-6$.
  4. Other values: if $k\neq -6$ the equation reduces to a false statement, so there is no solution.

The answer is $k=-6$. In a grid-in question you would enter -6.

$k$ 取何值时，$6(x-2)=2(3x+k)$ 有无穷多解？

  1. 展开：$6x-12=6x+2k$。
  2. 比较：两边 $x$ 的系数都是 $6$，所以当常数项相等时，方程对每个 $x$ 都成立。
  3. 令常数项相等：$-12=2k$，所以 $k=-6$。
  4. 其他取值：若 $k\neq -6$，方程化为假命题，无解。

答案是 $k=-6$。在填空题 (grid-in) 中应输入 -6。

Isolating a variable in a formula在公式中分离变量

Solving for one letter in a formula uses the same inverse operations; the other letters are treated like numbers. Work from the outside in: undo the last operation first.

在公式中解出某个字母，用的仍是逆运算，其余字母当作数字处理。由外向内：先撤销最后一步运算。

Worked Example 1.3: solve a formula for one variable例题 1.3：在公式中解出某个变量

The area of a trapezoid is $A=\frac{1}{2}h(b_1+b_2)$. Solve for $b_1$.

  1. Clear the fraction: multiply both sides by $2$ to get $2A=h(b_1+b_2)$.
  2. Undo the multiplication by $h$: divide both sides by $h$ to get $\frac{2A}{h}=b_1+b_2$.
  3. Isolate: subtract $b_2$, so $b_1=\frac{2A}{h}-b_2$.
  4. Check with numbers: for $A=36$, $h=6$, $b_2=4$ the formula gives $b_1=12-4=8$, and $\frac{1}{2}\cdot 6\cdot(8+4)=36$.

Why it works: the formula is just an equation in which $b_1$ is the unknown.

梯形面积 $A=\frac{1}{2}h(b_1+b_2)$，解出 $b_1$。

  1. 去分母：两边乘 $2$，得 $2A=h(b_1+b_2)$。
  2. 撤销乘以 $h$：两边除以 $h$，得 $\frac{2A}{h}=b_1+b_2$。
  3. 分离：两边减 $b_2$，得 $b_1=\frac{2A}{h}-b_2$。
  4. 用数检验：取 $A=36$，$h=6$，$b_2=4$，公式给出 $b_1=12-4=8$，而 $\frac{1}{2}\cdot 6\cdot(8+4)=36$。

原理：公式就是以 $b_1$ 为未知数的方程。

Creating an equation from context由情境列方程

In a word problem, name the unknown, then translate each phrase: "per" signals multiplication by a rate, "a fixed fee" is a constant, "total" signals a sum. Solve, then answer the question that was asked, with units.

应用题 (word problem) 先给未知数命名，再逐句翻译："per"（每）表示乘以单价或速率，固定费用是常数，"total"（总计）表示求和。求解后回答题目所问，并带上单位。

Worked Example 1.4: build and solve an equation例题 1.4：列方程并求解

A gym charges a one-time sign-up fee of 40 dollars plus 35 dollars per month. Maya paid 285 dollars in total. For how many months was she a member?

  1. Define: let $m$ be the number of months.
  2. Translate: fixed fee plus monthly charge equals total, so $40+35m=285$.
  3. Solve: $35m=245$, so $m=7$.
  4. In context: Maya was a member for 7 months. Check: $40+35\cdot 7=285$.

Why it works: the 40 dollars does not depend on $m$, so only the monthly part is multiplied by $m$.

某健身房收取一次性注册费 40 美元，外加每月 35 美元。小玛雅共付了 285 美元。她当了几个月会员？

  1. 设元：设 $m$ 为月数。
  2. 翻译：固定费用加月费等于总额，所以 $40+35m=285$。
  3. 求解：$35m=245$，所以 $m=7$。
  4. 结合情境：小玛雅当了 7 个月会员。检验：$40+35\cdot 7=285$。

原理：40 美元与 $m$ 无关，所以只有月费部分乘以 $m$。

Common mistakes
  • Subtracting only from one side. Every operation must be applied to both sides.
  • Distributing to the first term only: $3(2x-5)$ is $6x-15$, not $6x-5$.
  • Concluding "no solution" when you get $x=0$. A solution of $0$ is still one solution; only a false statement like $0=-12$ means no solution.
常见错误
  • 只对一边做运算。每个运算必须对两边同时进行。
  • 括号只乘第一项：$3(2x-5)$ 是 $6x-15$，不是 $6x-5$。
  • 得到 $x=0$ 就说"无解"。解为 $0$ 仍然是一个解；只有像 $0=-12$ 这样的假命题才表示无解。

Linear Equations in Two Variables二元一次方程

Learning objectives学习目标
  • Write a line in slope-intercept form $y=mx+b$ and in standard form $Ax+By=C$, and convert between them.
  • Calculate the slope from two points and read the y-intercept and x-intercept from an equation.
  • Write the equation of a line from a slope and a point, or from two points.
  • Interpret the slope as a rate of change and the intercept as an initial value in context.
  • Interpret each term of a standard-form equation such as $12a+8c=960$.
  • 写出直线的斜截式 (slope-intercept form) $y=mx+b$ 与一般式 (standard form) $Ax+By=C$，并互相转换。
  • 由两点计算斜率 (slope)，由方程读出 y 轴截距 (y-intercept) 与 x 轴截距。
  • 由斜率和一点，或由两点写出直线方程。
  • 在情境中 (in context) 把斜率解释为变化率 (rate of change)，把截距解释为初始值 (initial value)。
  • 解释一般式方程（如 $12a+8c=960$）中每一项的含义。

A linear equation in two variables, such as $y=2x+1$ or $3x+4y=24$, has a straight line as its graph: every point $(x,y)$ on the line makes the equation true, and every point off the line makes it false. Two forms matter on the SAT.

二元一次方程（如 $y=2x+1$ 或 $3x+4y=24$）的图像是一条直线：直线上每个点 $(x,y)$ 都使方程成立，直线外的点都不成立。SAT 中有两种形式最常用。

Standard form$Ax+By=C$x-intercept $(\frac{C}{A},0)$ and y-intercept $(0,\frac{C}{B})$; slope $-\frac{A}{B}$
形式方程可直接读出

Slope斜率

The slope measures steepness: $m=\frac{\text{rise}}{\text{run}}=\frac{y_2-y_1}{x_2-x_1}$. A positive slope rises left to right, a negative slope falls, a horizontal line has slope $0$, and a vertical line has undefined slope. Subtract the coordinates in the same order in the numerator and the denominator.

斜率衡量陡峭程度：$m=\frac{\text{rise}}{\text{run}}=\frac{y_2-y_1}{x_2-x_1}$。斜率为正的直线从左到右上升，为负则下降，水平线斜率为 $0$，竖直线斜率不存在。分子分母中的坐标要按相同顺序相减。

Worked Example 2.1: write a line from two points例题 2.1：由两点写出直线方程

A line passes through $(2,5)$ and $(6,13)$. Write its equation in slope-intercept form and in standard form.

  1. Slope: $m=\frac{13-5}{6-2}=\frac{8}{4}=2$.
  2. Intercept: substitute $(2,5)$ into $y=2x+b$: $5=4+b$, so $b=1$.
  3. Slope-intercept form: $y=2x+1$.
  4. Standard form: move $y$ across: $2x-y=-1$.
  5. Check: $(6,13)$ gives $2\cdot 6+1=13$.

Why it works: a line is fixed by its slope and one point on it.

一条直线经过 $(2,5)$ 和 $(6,13)$。写出它的斜截式和一般式方程。

  1. 斜率：$m=\frac{13-5}{6-2}=\frac{8}{4}=2$。
  2. 截距：把 $(2,5)$ 代入 $y=2x+b$：$5=4+b$，所以 $b=1$。
  3. 斜截式：$y=2x+1$。
  4. 一般式：把 $y$ 移项：$2x-y=-1$。
  5. 检验：$(6,13)$ 代入得 $2\cdot 6+1=13$。

原理：斜率和直线上一点就确定了一条直线。

Converting between forms两种形式互换

Worked Example 2.2: convert standard form to slope-intercept form例题 2.2：把一般式化为斜截式

Find the slope, y-intercept, and x-intercept of $3x+4y=24$.

  1. Solve for $y$: $4y=-3x+24$, so $y=-\frac{3}{4}x+6$.
  2. Read: the slope is $-\frac{3}{4}$ and the y-intercept is $(0,6)$.
  3. x-intercept: set $y=0$: $3x=24$, so $x=8$ and the point is $(8,0)$.
  4. Check: $3\cdot 8+4\cdot 0=24$.

Why it works: the y-intercept is the point with $x=0$ and the x-intercept is the point with $y=0$.

求 $3x+4y=24$ 的斜率、y 轴截距和 x 轴截距。

  1. 解出 $y$：$4y=-3x+24$，所以 $y=-\frac{3}{4}x+6$。
  2. 读出：斜率为 $-\frac{3}{4}$，y 轴截距为 $(0,6)$。
  3. x 轴截距：令 $y=0$：$3x=24$，所以 $x=8$，交点为 $(8,0)$。
  4. 检验：$3\cdot 8+4\cdot 0=24$。

原理：y 轴截距是 $x=0$ 的点，x 轴截距是 $y=0$ 的点。

Slope and intercept in context在情境中解释斜率与截距

When $x$ and $y$ are real quantities, the slope is the rate of change: how much $y$ changes for each 1-unit increase in $x$, with units "$y$-units per $x$-unit". The y-intercept is the initial value: the value of $y$ when $x=0$. Always say in context what the number means; a bare "the slope is 12" is not an answer.

当 $x$、$y$ 是实际的量时，斜率就是变化率：$x$ 每增加 1 个单位，$y$ 变化多少，单位是"$y$ 的单位每 $x$ 的单位"。y 轴截距是初始值：$x=0$ 时 $y$ 的值。一定要结合情境说明数字的含义，只写"斜率是 12"不是答案。

Worked Example 2.3: model a draining tank例题 2.3：为排水的水箱建模

A tank holds 120 liters. It drains steadily and holds 90 liters after 5 minutes. Write the volume $V$ after $t$ minutes, interpret the slope and intercept, and find when the tank is empty.

  1. Points: $(0,120)$ and $(5,90)$.
  2. Slope: $\frac{90-120}{5-0}=-6$, so the volume changes by $-6$ liters each minute.
  3. Equation: the y-intercept is $120$, so $V=120-6t$.
  4. In context: $-6$ is the rate of change (the tank loses 6 liters per minute) and $120$ is the initial value (the volume at $t=0$).
  5. Empty: $120-6t=0$ gives $t=20$ minutes.

Why it works: a constant draining rate means equal volumes leave in equal times, which is exactly a linear model.

一个水箱有 120 升水，匀速排水，5 分钟后剩 90 升。写出 $t$ 分钟后的水量 $V$，解释斜率与截距，并求水箱何时排空。

  1. 两点：$(0,120)$ 和 $(5,90)$。
  2. 斜率：$\frac{90-120}{5-0}=-6$，即每分钟水量变化 $-6$ 升。
  3. 方程：y 轴截距为 $120$，所以 $V=120-6t$。
  4. 结合情境：$-6$ 是变化率（每分钟排出 6 升），$120$ 是初始值（$t=0$ 时的水量）。
  5. 排空：$120-6t=0$ 得 $t=20$ 分钟。

原理：排水速率恒定意味着相等时间排出相等水量，这正是线性模型。

Worked Example 2.4: read a standard-form equation in context例题 2.4：在情境中解读一般式方程

A theater sells adult tickets for 12 dollars and child tickets for 8 dollars. The equation $12a+8c=960$ models a night when ticket sales total 960 dollars, where $a$ is the number of adult tickets and $c$ is the number of child tickets. What does the point $(80,0)$ on the graph mean?

  1. Substitute: $12\cdot 80+8\cdot 0=960$, so $(80,0)$ is on the line.
  2. Interpret: $c=0$ means no child tickets, so the point says that 80 adult tickets alone bring in 960 dollars.
  3. Slope: solving for $c$ gives $c=-\frac{3}{2}a+120$. The slope $-\frac{3}{2}$ means that each additional adult ticket sold goes with $1.5$ fewer child tickets at the same total.

Why it works: in standard form each term is a quantity times its price, and the right side is the total.

剧院成人票 12 美元，儿童票 8 美元。方程 $12a+8c=960$ 描述票款总额为 960 美元的一晚，其中 $a$ 为成人票张数，$c$ 为儿童票张数。图像上的点 $(80,0)$ 表示什么？

  1. 代入：$12\cdot 80+8\cdot 0=960$，所以 $(80,0)$ 在直线上。
  2. 解释：$c=0$ 表示没有儿童票，所以该点说明仅 80 张成人票就收入 960 美元。
  3. 斜率：解出 $c$ 得 $c=-\frac{3}{2}a+120$。斜率 $-\frac{3}{2}$ 表示在总额不变时，每多卖一张成人票就少卖 $1.5$ 张儿童票。

原理：一般式中每一项是数量乘单价，右边是总额。

Common mistakes

  • Subtracting coordinates in different orders: $\frac{y_2-y_1}{x_1-x_2}$ flips the sign.
  • Calling the y-intercept "the number in front". The initial value is the output at $x=0$, which you must also state with units.
常见错误

Linear Functions一次函数

Learning objectives学习目标

  • Build a linear function $f(x)=mx+b$ from a description, a table, or two points.

  • 用函数记号 (function notation) 对给定输入求 $f(x)$，并由给定输出求输入。
  • 由描述、表格或两点建立一次函数 (linear function) $f(x)=mx+b$。
  • 解 $f(x)=0$ 求一次函数的 x 轴截距 (x-intercept)。
  • 由斜率判断两条直线是否平行 (parallel) 或垂直 (perpendicular)。

A linear function is a function whose graph is a line: $f(x)=mx+b$, where $m$ is the slope and $b=f(0)$ is the y-intercept. Function notation $f(x)$ is read "$f$ of $x$" and means the output when the input is $x$. It is not $f$ multiplied by $x$. The statement $f(3)=7$ says the point $(3,7)$ is on the graph.

一次函数 (linear function) 是图像为直线的函数：$f(x)=mx+b$，其中 $m$ 是斜率，$b=f(0)$ 是 y 轴截距。函数记号 (function notation) $f(x)$ 读作"$f$ of $x$"，表示输入为 $x$ 时的输出，不是 $f$ 乘以 $x$。$f(3)=7$ 表示点 $(3,7)$ 在图像上。

Evaluating and inverting求值与求输入

Worked Example 3.1: evaluate and solve with function notation例题 3.1：用函数记号求值与解方程

Let $f(x)=4x-9$. Find $f(5)$, $f(-2)$, the value of $x$ for which $f(x)=23$, and $f(a+1)$.

  1. Evaluate: $f(5)=4\cdot 5-9=11$.
  2. Negative input: $f(-2)=4\cdot(-2)-9=-17$.
  3. Given output: solve $4x-9=23$, so $4x=32$ and $x=8$.
  4. Expression as input: replace every $x$ by $(a+1)$: $f(a+1)=4(a+1)-9=4a-5$.
  5. Check: $f(8)=4\cdot 8-9=23$.

Why it works: $f(\text{input})$ means substitute the input everywhere $x$ appears.

设 $f(x)=4x-9$。求 $f(5)$、$f(-2)$、使 $f(x)=23$ 的 $x$，以及 $f(a+1)$。

  1. 求值：$f(5)=4\cdot 5-9=11$。
  2. 负输入：$f(-2)=4\cdot(-2)-9=-17$。
  3. 已知输出：解 $4x-9=23$，$4x=32$，$x=8$。
  4. 表达式作输入：把每个 $x$ 换成 $(a+1)$：$f(a+1)=4(a+1)-9=4a-5$。
  5. 检验：$f(8)=4\cdot 8-9=23$。

原理：$f(\text{input})$ 就是把 $x$ 出现的每处都换成输入。

Building a linear function建立一次函数

Two facts about a linear function are enough: two input-output pairs, or the slope and one pair. Compute the slope first, then use one pair to find $b$.

知道一次函数的两个事实就够了：两组输入输出，或斜率加一组输入输出。先求斜率，再用一组数求 $b$。

Worked Example 3.2: build $f$ from two values例题 3.2：由两个函数值建立 $f$

A linear function $f$ satisfies $f(2)=7$ and $f(8)=-5$. Write $f(x)$ and find its x-intercept.

  1. Slope: $m=\frac{-5-7}{8-2}=\frac{-12}{6}=-2$.
  2. Intercept: $f(2)=-2\cdot 2+b=7$, so $b=11$.
  3. Function: $f(x)=-2x+11$.
  4. x-intercept: solve $f(x)=0$: $-2x+11=0$, so $x=\frac{11}{2}=5.5$.
  5. Check: $f(8)=-16+11=-5$.

Why it works: the x-intercept is the input whose output is $0$.

一次函数 $f$ 满足 $f(2)=7$ 与 $f(8)=-5$。写出 $f(x)$ 并求其 x 轴截距。

  1. 斜率：$m=\frac{-5-7}{8-2}=\frac{-12}{6}=-2$。
  2. 截距：$f(2)=-2\cdot 2+b=7$，所以 $b=11$。
  3. 函数：$f(x)=-2x+11$。
  4. x 轴截距：解 $f(x)=0$：$-2x+11=0$，所以 $x=\frac{11}{2}=5.5$。
  5. 检验：$f(8)=-16+11=-5$。

原理：x 轴截距就是输出为 $0$ 的输入。

Parallel and perpendicular lines平行线与垂直线

Two lines are parallel when they have the same slope and different y-intercepts; they never meet. Two lines are perpendicular when their slopes are negative reciprocals: if one slope is $m$, the other is $-\frac{1}{m}$, so the product of the slopes is $-1$. A horizontal line (slope $0$) is perpendicular to a vertical line, which is the one case that does not fit the product rule.

两条直线平行当且仅当斜率相同而 y 轴截距不同，它们永不相交。两条直线垂直当且仅当斜率互为负倒数 (negative reciprocal)：若一条斜率为 $m$，另一条为 $-\frac{1}{m}$，即斜率之积为 $-1$。水平线（斜率 $0$）与竖直线垂直，这是唯一不适用乘积规则的情形。

Worked Example 3.3: parallel and perpendicular through a point例题 3.3：过一点的平行线与垂直线

Line $\ell$ is $y=\frac{1}{2}x-2$. Write the equation of (a) the line parallel to $\ell$ through $(4,5)$ and (b) the line perpendicular to $\ell$ through $(4,5)$.

  1. (a) Parallel: the slope stays $\frac{1}{2}$. From $5=\frac{1}{2}\cdot 4+b$ we get $b=3$, so $y=\frac{1}{2}x+3$.
  2. (b) Perpendicular: the slope is the negative reciprocal of $\frac{1}{2}$, which is $-2$. From $5=-2\cdot 4+b$ we get $b=13$, so $y=-2x+13$.
  3. Check (b): $\frac{1}{2}\cdot(-2)=-1$, and at $x=4$, $y=-8+13=5$.

Why it works: parallel lines share a direction, and rotating a direction by a right angle swaps rise and run and flips one sign.

直线 $\ell$ 为 $y=\frac{1}{2}x-2$。写出 (a) 过 $(4,5)$ 且平行于 $\ell$ 的直线，(b) 过 $(4,5)$ 且垂直于 $\ell$ 的直线。

  1. (a) 平行：斜率仍为 $\frac{1}{2}$。由 $5=\frac{1}{2}\cdot 4+b$ 得 $b=3$，所以 $y=\frac{1}{2}x+3$。
  2. (b) 垂直：斜率是 $\frac{1}{2}$ 的负倒数，即 $-2$。由 $5=-2\cdot 4+b$ 得 $b=13$，所以 $y=-2x+13$。
  3. 检验 (b)：$\frac{1}{2}\cdot(-2)=-1$，且 $x=4$ 时 $y=-8+13=5$。

原理：平行线方向相同；把方向旋转直角会交换升降与水平增量并改变一个符号。

Worked Example 3.4: x-intercept of a perpendicular line例题 3.4：垂直线的 x 轴截距

Line $m$ is $3x+5y=15$. Line $n$ is perpendicular to $m$ and passes through $(0,-2)$. What is the x-intercept of $n$?

  1. Slope of $m$: $5y=-3x+15$, so $y=-\frac{3}{5}x+3$ and the slope is $-\frac{3}{5}$.
  2. Slope of $n$: the negative reciprocal is $\frac{5}{3}$.
  3. Equation of $n$: it passes through $(0,-2)$, so $y=\frac{5}{3}x-2$.
  4. x-intercept: set $y=0$: $\frac{5}{3}x=2$, so $x=\frac{6}{5}$.
  5. Grid-in: enter 6/5 or 1.2.

Why it works: the point $(0,-2)$ gives the y-intercept directly, so no solving for $b$ is needed.

直线 $m$ 为 $3x+5y=15$。直线 $n$ 垂直于 $m$ 且过 $(0,-2)$。$n$ 的 x 轴截距是多少？

  2. $n$ 的斜率：负倒数为 $\frac{5}{3}$。
  3. $n$ 的方程：过 $(0,-2)$，所以 $y=\frac{5}{3}x-2$。
  4. x 轴截距：令 $y=0$：$\frac{5}{3}x=2$，所以 $x=\frac{6}{5}$。
  5. 填空题：输入 6/5 或 1.2。

原理：点 $(0,-2)$ 直接给出 y 轴截距，无需再解 $b$。

  • Calling two lines parallel because their equations look similar. Compare slopes after both are in slope-intercept form.

Worked Example 4.1: solve by substitution例题 4.1：用代入法求解

Solve $y=2x-1$ and $3x+2y=12$.

  1. Substitute: replace $y$ in the second equation: $3x+2(2x-1)=12$.
  2. Solve for $x$: $3x+4x-2=12$, so $7x=14$ and $x=2$.
  3. Back-substitute: $y=2\cdot 2-1=3$.
  4. Check in both equations: $3\cdot 2+2\cdot 3=12$ and $3=2\cdot 2-1$.
  5. Answer: $(x,y)=(2,3)$.

Why it works: the point must satisfy the first equation, so $y$ and $2x-1$ are the same number.

解 $y=2x-1$ 与 $3x+2y=12$。

  1. 代入：在第二个方程中替换 $y$：$3x+2(2x-1)=12$。

Worked Example 4.2: solve by elimination例题 4.2：用消元法求解

Solve $3x+2y=18$ and $2x-5y=-7$.

  1. Match the $y$ coefficients: multiply the first equation by $5$ and the second by $2$: $15x+10y=90$ and $4x-10y=-14$.
  2. Add: the $y$ terms cancel, leaving $19x=76$, so $x=4$.
  3. Back-substitute: $3\cdot 4+2y=18$ gives $2y=6$, so $y=3$.
  4. Check: $2\cdot 4-5\cdot 3=8-15=-7$.
  5. Answer: $(x,y)=(4,3)$.

Why it works: multiplying an equation by a nonzero number does not change its solutions, and adding true equations gives a true equation.

解 $3x+2y=18$ 与 $2x-5y=-7$。

  1. 使 $y$ 的系数配平：第一个方程乘 $5$，第二个乘 $2$：$15x+10y=90$ 与 $4x-10y=-14$。
  2. 相加：$y$ 项抵消，得 $19x=76$，所以 $x=4$。
  3. 回代：$3\cdot 4+2y=18$ 得 $2y=6$，所以 $y=3$。
  4. 检验：$2\cdot 4-5\cdot 3=8-15=-7$。
  5. 答案：$(x,y)=(4,3)$。

原理：方程两边乘非零数不改变解，真等式相加仍是真等式。

How many solutions?有几个解？

Write both equations as lines. If the slopes differ, the lines intersect at exactly one point. If the lines have the same slope and different y-intercepts, they are parallel and the system has no solution. If they have the same slope and the same y-intercept, they are the same line and the system has infinitely many solutions. In elimination, the same cases appear as a false statement (such as $0=5$) or a true one ($0=0$).

把两个方程都看作直线。若斜率不同，两直线恰好相交于一点。若斜率相同而 y 轴截距不同，则两线平行，方程组无解。若斜率与截距都相同，则是同一条直线，方程组有无穷多解。在消元法中，这两种情形表现为假命题（如 $0=5$）或真命题（$0=0$）。

For a system $a_1x+b_1y=c_1$ and $a_2x+b_2y=c_2$, the slopes match when $\frac{a_1}{a_2}=\frac{b_1}{b_2}$. Then the system has no solution if also $\frac{c_1}{c_2}$ is different, and infinitely many solutions if all three ratios are equal.

对方程组 $a_1x+b_1y=c_1$、$a_2x+b_2y=c_2$，当 $\frac{a_1}{a_2}=\frac{b_1}{b_2}$ 时斜率相同。此时若 $\frac{c_1}{c_2}$ 不同则无解；若三个比值都相等则有无穷多解。

Worked Example 4.3: parameter for no solution例题 4.3：求使方程组无解的参数

For what value of $k$ does the system $2x+5y=9$ and $kx+15y=20$ have no solution?

  1. Same slope needed: multiply the first equation by $3$ so the $y$ coefficients match: $6x+15y=27$.
  2. Match the $x$ coefficients: the second equation must then have $k=6$ for the slopes to be equal.
  3. Constants differ: with $k=6$ the system is $6x+15y=27$ and $6x+15y=20$, which cannot both hold, because $27\neq 20$.
  4. Answer: $k=6$. For every other $k$ the slopes differ and there is exactly one solution.

Even though the question is about no solution, the grid-in answer is one number: 6.

$k$ 取何值时，方程组 $2x+5y=9$ 与 $kx+15y=20$ 无解？

  1. 需要斜率相同：第一个方程乘 $3$，使 $y$ 的系数一致：$6x+15y=27$。
  2. 对齐 $x$ 的系数：此时第二个方程必须有 $k=6$，斜率才相等。
  3. 常数项不同：$k=6$ 时方程组为 $6x+15y=27$ 与 $6x+15y=20$，二者不可能同时成立，因为 $27\neq 20$。
  4. 答案：$k=6$。$k$ 取其他值时斜率不同，恰有一个解。

虽然题目问的是无解，填空题的答案仍是一个数：6。
