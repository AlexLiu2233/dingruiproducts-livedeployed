Function Notation, Domain and Range函数记号、定义域与值域

Learning objectives学习目标
  • Define a function and apply the vertical line test to a graph.
  • Use function notation to evaluate $f(a)$ and $f(a+1)$ and to solve $f(x)=k$.
  • Find the domain of a formula by excluding zero denominators and negative radicands.
  • State the range from a graph or from the shape of the formula.
  • Read inputs and outputs from a table and from a graph without mixing up $x$ and $y$.
  • 定义函数 (function)，并对图像使用垂直线检验。
  • 用函数记号 (function notation) 计算 $f(a)$ 与 $f(a+1)$，并解 $f(x)=k$。
  • 通过排除分母为零和被开方数为负的情形，求公式的定义域 (domain)。
  • 根据图像或公式的形状写出值域 (range)。
  • 读表和读图时不混淆 $x$ 与 $y$（输入与输出）。

What a function is什么是函数

A function is a rule that gives each allowed input exactly one output. The symbol $f(x)$, read “f of x”, is the output of the function named $f$ when the input is $x$. It is not $f$ times $x$. To evaluate $f(3)$, replace every $x$ in the formula by $3$. On a graph, the vertical line test checks the rule: if some vertical line meets the curve twice, one input has two outputs and the graph is not a function.

函数 (function) 是一条规则：每个允许的输入恰好对应一个输出。记号 $f(x)$ 读作 “f of x”，表示名为 $f$ 的函数在输入为 $x$ 时的输出，它不是 $f$ 乘以 $x$。计算 $f(3)$ 就是把公式里每个 $x$ 换成 $3$。在图像上可用垂直线检验：若某条竖直线与曲线相交两次，则同一个输入有两个输出，该图像不是函数。

The set of allowed inputs is the domain; the set of outputs that actually occur is the range. A quick memory aid: the domain lives on the horizontal axis, the range on the vertical axis.

允许输入的集合叫定义域 (domain)；实际出现的输出的集合叫值域 (range)。速记：定义域在横轴上，值域在纵轴上。

Evaluating and substituting求值与代入

Whatever sits inside the brackets replaces $x$ everywhere, as a whole. If $f(x)=x^2-4x$, then $f(a+1)=(a+1)^2-4(a+1)$, and $f(-3)=(-3)^2-4(-3)=21$. Writing the substituted value in brackets first prevents the most common sign error. A related task is solving $f(x)=k$: set the formula equal to $k$ and solve for $x$.

括号内的内容要作为一个整体替换每一个 $x$。若 $f(x)=x^2-4x$，则 $f(a+1)=(a+1)^2-4(a+1)$，而 $f(-3)=(-3)^2-4(-3)=21$。先把代入的值写进括号，能避免最常见的符号错误。相关的任务是解 $f(x)=k$：令公式等于 $k$，再求 $x$。

Worked Example: evaluate with a substitution例题：代入求值

Let $f(x)=3x^2-2x+5$. Find $f(-2)$ and write $f(a+1)$ as a simplified polynomial.

  1. Substitute with brackets: $f(-2)=3(-2)^2-2(-2)+5$.
  2. Compute: $3(4)+4+5=12+4+5=21$.
  3. Substitute the whole expression: $f(a+1)=3(a+1)^2-2(a+1)+5$.
  4. Expand: $3(a^2+2a+1)-2a-2+5=3a^2+6a+3-2a-2+5$.
  5. Combine like terms: $f(a+1)=3a^2+4a+6$.

Why it works: the brackets keep the sign of $-2$ and the whole of $a+1$ together. Check with $a=1$: $f(2)=12-4+5=13$, and $3+4+6=13$.

设 $f(x)=3x^2-2x+5$。求 $f(-2)$，并把 $f(a+1)$ 写成化简后的多项式。

  1. 带括号代入：$f(-2)=3(-2)^2-2(-2)+5$。
  2. 计算：$3(4)+4+5=12+4+5=21$。
  3. 代入整个表达式：$f(a+1)=3(a+1)^2-2(a+1)+5$。
  4. 展开：$3(a^2+2a+1)-2a-2+5=3a^2+6a+3-2a-2+5$。
  5. 合并同类项：$f(a+1)=3a^2+4a+6$。

原理：括号保住了 $-2$ 的符号，也把 $a+1$ 当作一个整体。取 $a=1$ 检验：$f(2)=12-4+5=13$，而 $3+4+6=13$。

Domain and range from a formula由公式求定义域与值域

For $g(x)=\dfrac{\sqrt{x-2}}{x-5}$ two rules act at once. The square root needs $x-2\ge 0$, so $x\ge 2$. The denominator needs $x\ne 5$. Together the domain is $[2,5)\cup(5,\infty)$. Notice that the root allows $x=2$ (the radicand is $0$, which is fine) but the denominator forbids $x=5$.

对 $g(x)=\dfrac{\sqrt{x-2}}{x-5}$，两条规则同时起作用。平方根要求 $x-2\ge 0$，即 $x\ge 2$；分母要求 $x\ne 5$。合起来定义域是 $[2,5)\cup(5,\infty)$。注意根号允许 $x=2$（被开方数为 $0$，没有问题），而分母不允许 $x=5$。

The range comes from the shape. A square root is never negative, so $\sqrt{x-2}\ge 0$ and $f(x)=\sqrt{x-2}+1$ takes every value from $1$ upward. The graph in Figure 2.1 shows both sets at a glance.

值域要看形状。平方根不会为负，所以 $\sqrt{x-2}\ge 0$，于是 $f(x)=\sqrt{x-2}+1$ 取遍从 $1$ 起向上的所有值。图 2.1 一眼就能读出这两个集合。

Worked Example: domain with a root and a denominator例题：含根号与分母的定义域

Find the domain of $g(x)=\dfrac{\sqrt{x-2}}{x-5}$.

  1. Root condition: $x-2\ge 0$, so $x\ge 2$.
  2. Denominator condition: $x-5\ne 0$, so $x\ne 5$.
  3. Both must hold: all $x\ge 2$ except $x=5$.
  4. Interval form: $[2,5)\cup(5,\infty)$.

Why it works: each restriction removes inputs the formula cannot accept, and the domain keeps only what survives all of them. Test: $g(2)=0$ is defined, $g(5)$ is not.

求 $g(x)=\dfrac{\sqrt{x-2}}{x-5}$ 的定义域。

  1. 根号条件：$x-2\ge 0$，所以 $x\ge 2$。
  2. 分母条件：$x-5\ne 0$，所以 $x\ne 5$。
  3. 两个条件必须同时成立：所有 $x\ge 2$，除去 $x=5$。
  4. 区间形式：$[2,5)\cup(5,\infty)$。

原理：每条限制都排除公式无法接受的输入，定义域只保留通过所有限制的值。检验：$g(2)=0$ 有定义，$g(5)$ 无定义。

Worked Example: range and solving f(x) = k from a graph例题：读值域并解 f(x) = k

For $f(x)=\sqrt{x-2}+1$ (Figure 2.1), state the range and find the input with $f(x)=3$.

  1. Since $\sqrt{x-2}\ge 0$, the smallest output is $f(2)=0+1=1$. The range is $y\ge 1$.
  2. Set $\sqrt{x-2}+1=3$, so $\sqrt{x-2}=2$.
  3. Square both sides: $x-2=4$, so $x=6$.
  4. Check in the original: $f(6)=\sqrt{4}+1=3$. Valid, and it is the point $(6,3)$ on the graph.

Why it works: squaring can add false roots, so the check in the original equation is part of the method. Here $x=6$ passes.

对 $f(x)=\sqrt{x-2}+1$（图 2.1），写出值域，并求使 $f(x)=3$ 的输入。

  1. 因为 $\sqrt{x-2}\ge 0$，最小输出是 $f(2)=0+1=1$，值域为 $y\ge 1$。
  2. 令 $\sqrt{x-2}+1=3$，得 $\sqrt{x-2}=2$。
  3. 两边平方：$x-2=4$，所以 $x=6$。
  4. 代回原式检验：$f(6)=\sqrt{4}+1=3$。成立，对应图上的点 $(6,3)$。

原理：平方可能引入增根，所以代回原方程检验是方法的一部分。这里 $x=6$ 通过检验。

Common Mistake: function notation and domain
  • Reading $f(x)$ as a product. $f(3)$ means “the output when $x=3$”, not $f\cdot 3$.
  • Assuming $f(a+b)=f(a)+f(b)$. For $f(x)=x^2$, $f(1+2)=9$ but $f(1)+f(2)=5$.
  • Swapping domain and range: the domain is the set of inputs ($x$), the range the set of outputs ($y$).
  • Writing $x>2$ for a square root when $x=2$ is allowed: the radicand may equal $0$.
常见错误：函数记号与定义域
  • 把 $f(x)$ 当作乘积。$f(3)$ 的意思是“$x=3$ 时的输出”，不是 $f\cdot 3$。
  • 认为 $f(a+b)=f(a)+f(b)$。对 $f(x)=x^2$，$f(1+2)=9$，但 $f(1)+f(2)=5$。
  • 把定义域与值域弄反：定义域是输入（$x$）的集合，值域是输出（$y$）的集合。
  • 平方根在 $x=2$ 允许时却写成 $x>2$：被开方数可以等于 $0$。

  • Write a line in slope-intercept, point-slope and standard form and convert between them.

  • Decide when two lines are parallel or perpendicular from their slopes.

  • 根据两点、图像或方程计算直线的斜率 (slope)。

Slope and the forms of a line斜率与直线的各种形式

A linear function $f(x)=mx+b$ changes by the same amount $m$ for every one-unit step in $x$. That constant is the slope: rise over run, $m=\dfrac{y_2-y_1}{x_2-x_1}$. Subtract the $y$ values and the $x$ values in the same order. The number $b$ is the y-intercept, the output when $x=0$.

一次函数 (linear function) $f(x)=mx+b$ 在 $x$ 每增加一个单位时，变化量都是同一个数 $m$。这个常数就是斜率：纵向增量比横向增量，$m=\dfrac{y_2-y_1}{x_2-x_1}$。分子分母中 $y$ 与 $x$ 的相减顺序必须一致。数 $b$ 是 y 截距，即 $x=0$ 时的输出。

Forms of a line
Slope-intercept: $y=mx+b$
Point-slope: $y-y_1=m(x-x_1)$
Standard: $Ax+By=C$, with slope $-\dfrac{A}{B}$
Horizontal: $y=c$ (slope $0$). Vertical: $x=c$ (slope undefined, not a function).
直线的形式
斜截式：$y=mx+b$
点斜式：$y-y_1=m(x-x_1)$
一般式：$Ax+By=C$，斜率为 $-\dfrac{A}{B}$
水平线：$y=c$（斜率 $0$）。竖直线：$x=c$（斜率不存在，不是函数）。

Intercepts截距

The y-intercept is the point where the line crosses the y-axis, so set $x=0$. The x-intercept is where it crosses the x-axis, so set $y=0$. For $y=2x-1$ in Figure 2.2: $x=0$ gives $(0,-1)$ and $y=0$ gives $x=\tfrac12$, the point $(\tfrac12,0)$.

y 截距是直线与 y 轴的交点，令 $x=0$；x 截距是与 x 轴的交点，令 $y=0$。对图 2.2 中的 $y=2x-1$：$x=0$ 得 $(0,-1)$，$y=0$ 得 $x=\tfrac12$，即点 $(\tfrac12,0)$。

Worked Example: line through two points例题：过两点的直线

Find the equation of the line through $(-1,5)$ and $(3,-3)$, then give both intercepts.

  1. Slope: $m=\dfrac{-3-5}{3-(-1)}=\dfrac{-8}{4}=-2$.
  2. Point-slope with $(-1,5)$: $y-5=-2(x+1)$.
  3. Simplify: $y=-2x-2+5=-2x+3$.
  4. y-intercept: $x=0$ gives $y=3$, the point $(0,3)$.
  5. x-intercept: $0=-2x+3$ gives $x=\tfrac32$, the point $(\tfrac32,0)$.

Why it works: any point on the line can anchor the point-slope form. Check with the second point: $-2(3)+3=-3$. It matches.

求过 $(-1,5)$ 和 $(3,-3)$ 的直线方程，并给出两个截距。

  1. 斜率：$m=\dfrac{-3-5}{3-(-1)}=\dfrac{-8}{4}=-2$。
  2. 用点 $(-1,5)$ 写点斜式：$y-5=-2(x+1)$。
  3. 化简：$y=-2x-2+5=-2x+3$。
  4. y 截距：$x=0$ 得 $y=3$，即点 $(0,3)$。
  5. x 截距：$0=-2x+3$ 得 $x=\tfrac32$，即点 $(\tfrac32,0)$。

原理：直线上任一点都可作为点斜式的锚点。用第二个点检验：$-2(3)+3=-3$，吻合。

Parallel and perpendicular lines平行线与垂直线

Two non-vertical lines are parallel when their slopes are equal and their intercepts differ (equal slopes with equal intercepts is the same line). They are perpendicular when the slopes multiply to $-1$: the slopes are negative reciprocals, such as $2$ and $-\tfrac12$, or $\tfrac25$ and $-\tfrac52$. A horizontal line is perpendicular to a vertical line even though no slope product exists.

两条非竖直线在斜率相等且截距不同时平行（斜率和截距都相等则是同一条直线）。当斜率相乘等于 $-1$ 时它们垂直：斜率互为负倒数，例如 $2$ 与 $-\tfrac12$，或 $\tfrac25$ 与 $-\tfrac52$。水平线与竖直线互相垂直，尽管此时不存在斜率乘积。

Worked Example: parallel line through a point例题：过一点作平行线

Find the line through $(8,1)$ that is parallel to $3x-4y=8$, in slope-intercept form.

  1. Rewrite the given line: $-4y=-3x+8$, so $y=\tfrac34x-2$. Slope $\tfrac34$.
  2. A parallel line has the same slope $\tfrac34$.
  3. Point-slope with $(8,1)$: $y-1=\tfrac34(x-8)$.
  4. Simplify: $y=\tfrac34x-6+1=\tfrac34x-5$.

Why it works: only the slope is inherited; the intercept $-5$ differs from $-2$, so the lines never meet. Check: at $x=8$, $\tfrac34(8)-5=1$.

求过 $(8,1)$ 且平行于 $3x-4y=8$ 的直线，写成斜截式。

  1. 改写已知直线：$-4y=-3x+8$，所以 $y=\tfrac34x-2$，斜率 $\tfrac34$。
  2. 平行线斜率相同，仍为 $\tfrac34$。
  3. 用点 $(8,1)$ 写点斜式：$y-1=\tfrac34(x-8)$。

The parabola and its features抛物线及其特征

A quadratic function has the form $f(x)=ax^2+bx+c$ with $a\ne 0$. Its graph is a parabola. If $a>0$ the parabola opens upward and the vertex is the lowest point; if $a<0$ it opens downward and the vertex is the highest point. The constant $c$ is the y-intercept, because $f(0)=c$. The vertical line through the vertex is the axis of symmetry, and the zeros are mirror images of each other across it.

二次函数的形式是 $f(x)=ax^2+bx+c$，其中 $a\ne 0$，图像是抛物线。若 $a>0$，开口向上，顶点是最低点；若 $a<0$，开口向下，顶点是最高点。常数 $c$ 是 y 截距，因为 $f(0)=c$。过顶点的竖直线是对称轴，零点关于它互为镜像。

For $2x^2-5x-3$: $D=(-5)^2-4(2)(-3)=25+24=49>0$, so there are two real zeros, $x=\dfrac{5\pm7}{4}$, which are $3$ and $-\tfrac12$. Polynomial functions: degree and end behavior多项式函数：次数与末端行为

Zeros, factors and multiplicity零点、因式与重数

By the factor theorem, $(x-a)$ is a factor of $p(x)$ exactly when $p(a)=0$. The remainder theorem adds that dividing $p(x)$ by $x-a$ leaves remainder $p(a)$. If a factor appears twice, as in $(x+1)^2$, the zero $x=-1$ has multiplicity $2$ and the graph touches the axis there without crossing; an odd multiplicity crosses.

根据因式定理 (factor theorem)，$(x-a)$ 是 $p(x)$ 的因式，当且仅当 $p(a)=0$。余数定理补充：用 $x-a$ 去除 $p(x)$，余数为 $p(a)$。若某个因式出现两次，如 $(x+1)^2$，则零点 $x=-1$ 的重数为 $2$，图像在该点只与 x 轴相切而不穿过；重数为奇数则穿过。

Rational functions and asymptotes有理函数与渐近线

A rational function is a quotient of polynomials. A vertical asymptote occurs at each zero of the denominator that is not cancelled by the numerator. If the factor cancels, there is only a hole: $g(x)=\dfrac{x^2-4}{x-2}=x+2$ for $x\ne2$ has a hole at $(2,4)$ and no vertical asymptote. The horizontal asymptote depends on degrees: numerator degree smaller gives $y=0$; equal degrees give $y=$ the ratio of leading coefficients; numerator degree larger gives none.

有理函数 (rational function) 是两个多项式之商。分母的每个未被分子约去的零点处都有一条垂直渐近线。若该因式被约去，则只有一个空洞：$g(x)=\dfrac{x^2-4}{x-2}=x+2$（$x\ne2$）在 $(2,4)$ 处有空洞，没有垂直渐近线。水平渐近线取决于次数：分子次数较小，得 $y=0$；次数相同，得 $y=$ 首项系数之比；分子次数较大则没有。

Exponential growth and decay指数增长与衰减

An exponential function has the form $f(x)=a\cdot b^x$ with $a\ne 0$, $b>0$ and $b\ne 1$. Since $b^0=1$, $f(0)=a$: the number in front is the starting amount. Each time $x$ increases by $1$, the output is multiplied by $b$. That constant ratio is what separates exponential change from linear change, where the output has a constant difference. If $b>1$ the function shows growth; if $0\lt b\lt 1$ it shows decay. For $a>0$ the graph stays above the x-axis and approaches the horizontal asymptote $y=0$ on one side (Figure 2.5).

指数函数 (exponential function) 的形式是 $f(x)=a\cdot b^x$，其中 $a\ne 0$，$b>0$ 且 $b\ne 1$。因为 $b^0=1$，所以 $f(0)=a$：前面的系数就是起始量。$x$ 每增加 $1$，输出就乘以 $b$。这个固定的比值正是指数变化与线性变化的区别，线性变化中输出的差是固定的。若 $b>1$，函数表示增长 (growth)；若 $0\lt b\lt 1$，表示衰减 (decay)。当 $a>0$ 时，图像始终在 x 轴上方，并在一侧趋近水平渐近线 $y=0$（图 2.5）。

A percent rate becomes a factor by adding or subtracting it from $1$: growth of $r$ per period gives $b=1+r$, decay of $r$ gives $b=1-r$. So $6\%$ growth means $b=1.06$ and $15\%$ decay means $b=0.85$. Halving every $h$ time units gives $A(t)=A_0\left(\tfrac12\right)^{t/h}$, where $h$ is the half-life.

把百分率与 $1$ 相加或相减，就得到因子：每期增长 $r$ 时 $b=1+r$，每期衰减 $r$ 时 $b=1-r$。所以增长 $6\%$ 即 $b=1.06$，衰减 $15\%$ 即 $b=0.85$。每经过 $h$ 个时间单位减半，则 $A(t)=A_0\left(\tfrac12\right)^{t/h}$，其中 $h$ 是半衰期 (half-life)。

Logarithms and their rules对数及其法则

A logarithm answers the question “what exponent?”: $\log_b y=x$ means exactly $b^x=y$ (with $b>0$, $b\ne1$, $y>0$). So $\log_2 8=3$ because $2^3=8$, and $\log_5\tfrac1{25}=-2$ because $5^{-2}=\tfrac1{25}$. On a calculator, $\log$ means base $10$ and $\ln$ means base $e\approx2.718$. The logarithm function $y=\log_b x$ undoes $y=b^x$: its domain is $x>0$, it passes through $(1,0)$ and it has the vertical asymptote $x=0$.

对数 (logarithm) 回答的问题是“指数是多少？”：$\log_b y=x$ 恰好意味着 $b^x=y$（其中 $b>0$，$b\ne1$，$y>0$）。所以 $\log_2 8=3$，因为 $2^3=8$；$\log_5\tfrac1{25}=-2$，因为 $5^{-2}=\tfrac1{25}$。在计算器上，$\log$ 表示以 $10$ 为底，$\ln$ 表示以 $e\approx2.718$ 为底。对数函数 $y=\log_b x$ 是 $y=b^x$ 的逆运算：定义域为 $x>0$，经过 $(1,0)$，有垂直渐近线 $x=0$。

Shifts, reflections and stretches平移、反射与伸缩

A transformation moves or reshapes the graph of a parent function such as $y=x^2$, $y=|x|$ or $y=\sqrt x$. Worked Example: build a transformed equation例题：写出变换后的方程

Start with $f(x)=x^2$. Shift it $3$ units left, reflect it across the x-axis, then shift it $5$ units up. Write the new function $g$ and give its vertex.

  1. Left $3$ (inside, opposite sign): $(x+3)^2$.
  2. Reflect across the x-axis (outside): $-(x+3)^2$.
  3. Up $5$ (outside): $g(x)=-(x+3)^2+5$.
  4. The vertex moves from $(0,0)$ to $(-3,5)$ and the parabola now opens down.
  5. Check a point: $g(-1)=-(2)^2+5=1$.

Why it works: the reflection is applied before the upward shift, so the $+5$ sits outside the negative sign. Writing $-\big((x+3)^2+5\big)$ instead would put the vertex at $(-3,-5)$.

从 $f(x)=x^2$ 出发，先左移 $3$ 个单位，再关于 x 轴反射，最后上移 $5$ 个单位。写出新函数 $g$ 并给出顶点。

  1. 左移 $3$（内部，符号相反）：$(x+3)^2$。
  2. 关于 x 轴反射（外部）：$-(x+3)^2$。
  3. 上移 $5$（外部）：$g(x)=-(x+3)^2+5$。
  4. 顶点从 $(0,0)$ 移到 $(-3,5)$，抛物线开口向下。

原理：反射在上移之前进行，所以 $+5$ 位于负号之外。若写成 $-\big((x+3)^2+5\big)$，顶点会变成 $(-3,-5)$。

Worked Example: where does a point go?例题：点移到哪里？

The point $(4,-2)$ lies on the graph of $y=f(x)$. Which point must lie on the graph of $y=2f(x-1)+3$?

  1. Inside $x-1$: the x-coordinate moves right $1$, from $4$ to $5$.
  2. Outside, stretch first: $2\times(-2)=-4$.
  3. Then shift up $3$: $-4+3=-1$.
  4. The image point is $(5,-1)$.

Why it works: substitute to check. At $x=5$, $y=2f(5-1)+3=2f(4)+3=2(-2)+3=-1$.

  2. 外部先伸缩：$2\times(-2)=-4$。

原理：代入检验：当 $x=5$ 时，$y=2f(5-1)+3=2f(4)+3=2(-2)+3=-1$。

Composition of functions复合函数

The composition $(f\circ g)(x)=f(g(x))$ feeds the output of $g$ into $f$. Work from the inside out: evaluate $g$ first, then apply $f$ to that result. Order matters, because in general $f(g(x))\ne g(f(x))$. A composition is not a product: $f(g(x))$ is not $f(x)\cdot g(x)$.

复合函数 (composition) $(f\circ g)(x)=f(g(x))$ 把 $g$ 的输出送入 $f$。由内向外计算：先求 $g$，再对结果应用 $f$。顺序很重要，一般来说 $f(g(x))\ne g(f(x))$。复合不是乘积：$f(g(x))$ 不等于 $f(x)\cdot g(x)$。

Worked Example: compose in both orders例题：两种顺序的复合

Let $f(x)=2x+1$ and $g(x)=x^2-3$. Find $f(g(2))$, $g(f(2))$ and a formula for $f(g(x))$.

  1. $g(2)=4-3=1$, so $f(g(2))=f(1)=2(1)+1=3$.
  2. $f(2)=5$, so $g(f(2))=g(5)=25-3=22$.
  3. Formula: $f(g(x))=2(x^2-3)+1=2x^2-5$.
  4. Check: $2(2)^2-5=3$, matching step 1.

Why it works: the inner function produces the input of the outer one. The two orders give $3$ and $22$, which shows that composition is not commutative.

设 $f(x)=2x+1$，$g(x)=x^2-3$。求 $f(g(2))$、$g(f(2))$ 以及 $f(g(x))$ 的公式。

  1. $g(2)=4-3=1$，所以 $f(g(2))=f(1)=2(1)+1=3$。
  2. $f(2)=5$，所以 $g(f(2))=g(5)=25-3=22$。
  3. 公式：$f(g(x))=2(x^2-3)+1=2x^2-5$。
  4. 检验：$2(2)^2-5=3$，与第 1 步一致。

原理：内层函数的输出就是外层函数的输入。两种顺序分别得到 $3$ 和 $22$，说明复合不满足交换律。

Inverse functions反函数

The inverse $f^{-1}$ undoes $f$: if $f(a)=b$ then $f^{-1}(b)=a$, and $f(f^{-1}(x))=x$. To find it, write $y=f(x)$, swap $x$ and $y$, and solve for $y$. The graph of $f^{-1}$ is the reflection of the graph of $f$ across the line $y=x$, so domain and range trade places. For example, $f(x)=3x-4$ has $f^{-1}(x)=\dfrac{x+4}{3}$, and $y=\log_2 x$ is the inverse of $y=2^x$. Note that $f^{-1}(x)$ is not $\dfrac{1}{f(x)}$.

反函数 (inverse function) $f^{-1}$ 抵消 $f$ 的作用：若 $f(a)=b$，则 $f^{-1}(b)=a$，且 $f(f^{-1}(x))=x$。求法：写成 $y=f(x)$，交换 $x$ 与 $y$，再解出 $y$。$f^{-1}$ 的图像是 $f$ 的图像关于直线 $y=x$ 的反射，所以定义域与值域互换。例如 $f(x)=3x-4$ 的反函数是 $f^{-1}(x)=\dfrac{x+4}{3}$，而 $y=\log_2 x$ 是 $y=2^x$ 的反函数。注意 $f^{-1}(x)$ 不是 $\dfrac{1}{f(x)}$。

Choosing the right kind of model选择合适的模型类型

A function model turns a description into a formula. First name the input (often time) and the output, each with units. Then look for the pattern of change. Equal steps in the input that add the same amount to the output mean a constant rate of change, so the model is linear. Equal steps that multiply the output by the same factor (a constant percent change) mean an exponential model. A quantity that rises to a maximum and falls again, such as the height of a thrown ball or an area built from a fixed length of fence, suggests a quadratic model.

函数模型 (model) 把文字描述变成公式。先说出输入（常常是时间）和输出，各带单位。然后观察变化的规律。输入每走相同的一步，输出都加上相同的量，说明变化率 (rate of change) 恒定，模型是一次（线性）的。每一步都把输出乘以相同的因子（百分比变化恒定），说明是指数模型。量先升到最大值再下降，例如抛出的球的高度，或用固定长度的篱笆围出的面积，提示二次模型。

Three standard models
Linear: $f(x)=mx+b$, with $b$ the initial value and $m$ the rate of change (output units per input unit)
Exponential: $f(x)=a\cdot b^x$, with $a$ the initial value and $b$ the factor per period ($b=1\pm r$)
Quadratic: $f(x)=ax^2+bx+c$, with $c$ the initial value and the vertex giving the maximum or minimum
三种标准模型
一次：$f(x)=mx+b$，$b$ 为初始值，$m$ 为变化率（每单位输入对应的输出单位）
指数：$f(x)=a\cdot b^x$，$a$ 为初始值，$b$ 为每期因子（$b=1\pm r$）
二次：$f(x)=ax^2+bx+c$，$c$ 为初始值，顶点给出最大值或最小值

Writing and interpreting a model in context结合情境写出并解释模型

The initial value is the output when the input is $0$: a joining fee, a starting balance, a launch height. The rate of change is how much the output changes per one unit of input, so its units are a ratio such as dollars per month or liters per minute. To interpret a constant in context, say what it measures, attach its units and refer to the situation; “the slope is $25$” is an incomplete answer, while “the cost rises by 25 dollars for each additional month” is complete. Finally, check the domain: counts are whole numbers, times and lengths are not negative, and a draining tank stops at empty.

初始值 (initial value) 是输入为 $0$ 时的输出：入会费、起始余额、发射高度等。变化率是输入每增加一个单位时输出的变化量，所以它的单位是一个比，例如“美元每月”或“升每分钟”。结合情境 (in context) 解释常数时，要说出它度量什么、带上单位并联系情境；“斜率是 $25$”是不完整的回答，而“每多一个月费用增加 25 美元”才完整。最后检查定义域：个数是整数，时间和长度不为负，排水的水箱到空为止。

Worked Example: a linear cost model例题：一次费用模型

A gym charges a one-time joining fee of 40 dollars plus 25 dollars per month. Write the total cost $C$ in dollars after $m$ months, find the cost for one year, and interpret both constants.

  1. Input $m$ (months), output $C$ (dollars).
  2. Initial value: at $m=0$ only the fee is paid, so $b=40$.
  3. Rate of change: $25$ dollars per month, so $C(m)=25m+40$.
  4. One year: $C(12)=25(12)+40=300+40=340$, so 340 dollars.
  5. In context: $40$ is the joining fee paid before any month; $25$ is the extra cost of each month. Domain: whole numbers $m\ge0$.

Why it works: the cost goes up by the same amount every month, which is the signature of a linear model.

某健身房收取一次性入会费 40 美元，另加每月 25 美元。写出 $m$ 个月后的总费用 $C$（美元），求一年的费用，并解释两个常数。

  1. 输入 $m$（月），输出 $C$（美元）。
  2. 初始值：$m=0$ 时只付入会费，所以 $b=40$。
  3. 变化率：每月 $25$ 美元，所以 $C(m)=25m+40$。
  4. 一年：$C(12)=25(12)+40=300+40=340$，即 340 美元。
  5. 结合情境：$40$ 是在任何月份之前支付的入会费；$25$ 是每多一个月的额外费用。定义域：整数 $m\ge0$。

原理：费用每月增加相同的量，这正是一次模型的特征。

Worked Example: linear or exponential from a table例题：由表格判断一次还是指数

A culture is measured each day: $x=0,1,2,3$ gives $y=200,240,288,345.6$. Write a model and predict $y$ at $x=5$.

  1. Differences: $40$, $48$, $57.6$; not constant, so not linear.
  2. Ratios: $\dfrac{240}{200}=\dfrac{288}{240}=\dfrac{345.6}{288}=1.2$; constant, so exponential.
  3. Initial value $a=200$ (the value at $x=0$), factor $b=1.2$ ($20\%$ growth per day): $y=200(1.2)^x$.
  4. $(1.2)^5=2.48832$, so $y=200\times2.48832\approx497.7$.

Why it works: equal input steps with a constant ratio define exponential change; the growth rate is $1.2-1=0.2$ per day.

每天测量一次某培养物：$x=0,1,2,3$ 时 $y=200,240,288,345.6$。写出模型并预测 $x=5$ 时的 $y$。

  1. 差：$40$、$48$、$57.6$；不恒定，所以不是一次的。
  2. 比：$\dfrac{240}{200}=\dfrac{288}{240}=\dfrac{345.6}{288}=1.2$；恒定，所以是指数的。
  3. 初始值 $a=200$（$x=0$ 时的值），因子 $b=1.2$（每天增长 $20\%$）：$y=200(1.2)^x$。
  4. $(1.2)^5=2.48832$，所以 $y=200\times2.48832\approx497.7$。

原理：输入步长相等且比值恒定，就是指数变化；增长率为每天 $1.2-1=0.2$。

Worked Example: a quadratic area model例题：二次面积模型

A farmer has $120$ m of fence to enclose a rectangle along a straight wall, so only three sides need fence. Write the area as a function of the width $x$ (the two sides perpendicular to the wall) and find the greatest possible area.

  1. The side parallel to the wall uses the rest of the fence: $120-2x$ m.
  2. Area: $A(x)=x(120-2x)=-2x^2+120x$ square meters.
  3. Domain in context: both lengths positive, so $0\lt x\lt 60$.
  4. Vertex: $x=-\dfrac{120}{2(-2)}=30$.
  5. $A(30)=30\times60=1800$ square meters.

Why it works: the leading coefficient $-2$ is negative, so the parabola opens down and its vertex is the maximum.

一位农民有 $120$ m 篱笆，要沿一堵直墙围成一个矩形，所以只有三条边需要篱笆。把面积写成宽 $x$（与墙垂直的两条边）的函数，并求最大面积。

  1. 与墙平行的一边用剩下的篱笆：$120-2x$ m。
  2. 面积：$A(x)=x(120-2x)=-2x^2+120x$ 平方米。
  3. 情境中的定义域：两边长度都为正，所以 $0\lt x\lt 60$。
  4. 顶点：$x=-\dfrac{120}{2(-2)}=30$。
  5. $A(30)=30\times60=1800$ 平方米。

原理：首项系数 $-2$ 为负，抛物线开口向下，顶点即为最大值。

  • Interpreting a slope without units or without the word “each” or “per”.
  • Keeping an answer outside the domain, such as a negative time or a fractional number of people.
常见错误：建模失误
  • 从 $1$ 而不是 $0$ 开始计数：若注册时就付入会费，则 $C(0)=40$，而不是 $C(1)=40$。
  • 对百分比变化使用一次模型。百分比恒定意味着比值恒定，模型应为指数的。
  • 解释斜率时不带单位，或不说“每”。
  • 保留定义域之外的答案，例如负的时间或非整数的人数。
